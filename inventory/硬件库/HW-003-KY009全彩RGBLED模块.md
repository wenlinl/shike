## 功能

- 灯珠内部集成红、绿、蓝三颗 LED，通过 PWM 调节三色亮度，可混合出几乎任意颜色；
- 板已焊好限流电阻，**ESP32-S3 GPIO 直接驱动，不用外接电阻**。

## 引脚说明

| 引脚 | 说明 |
|---|---|
| - | GND（共阴极公共地） |
| R | 红色通道 |
| G | 绿色通道 |
| B | 蓝色通道 |

## 接线定义

1. `-` → GND（共阴极公共地）；
2. R → ESP32 PWM 引脚（红色通道）；
3. G → ESP32 PWM 引脚（绿色通道）；
4. B → ESP32 PWM 引脚（蓝色通道）。

> 注意：共阴极，引脚输出**高电平**点亮对应颜色；想要渐变变色，要使用 PWM 输出。

## 项目可用场景（食材识别硬件）

| 颜色 | 含义 |
|---|---|
| 绿色 | 识别正常、系统就绪 |
| 红色 | 识别失败 / 异常告警 |
| 黄色 | 正在图像推理中 |
| 蓝色 | WiFi 正在配网连接 |

## ⚠️ 小坑提醒

ESP32-S3 不是所有 GPIO 都支持硬件 PWM，写代码时尽量选用支持 LEDC 的引脚。
