# 食刻 ShiKe · 项目资料库

按"通用核心 + 活动定制"组织，每个活动建一个文件夹，只放该活动需要的定制文案。

## 结构

```text
项目资料/
├── README.md                          # 本索引与使用说明
├── 通用/                              # 所有活动都能用的核心资料
│   ├── 食刻-核心资料-通用版.md         # 分条核心信息母版（无平台特定内容）
│   └── 食刻-产品介绍-对外简单版.md     # 一页式对外产品介绍
│   ├── 食刻-项目介绍.md                # 项目全景介绍（起源/产品/进展/团队/规划）
│   └── 食刻-商业计划书.md              # 商业计划书（市场/竞品/模式/风险/融资）
├── 活动-AWS/                         # AWS 主办活动的提交文案
│   └── 创业想法-提交文案-AWS主办版.md  # 含 AWS 技术方案（仅该活动使用）
├── 活动-XProgram-瑞安办公xBottleDream/ # X Program（瑞安办公 × BottleDream）报名提交文案
│   └── XProgram-产品-方案-共创思路.md   # 产品核心内容，不含平台特定表述
├── 活动-ITEC-2026-OPC/                 # 当前活动：ITEC 2026（OPC 报名材料）
├── 活动-奇绩创坛2026秋/                 # 当前活动：奇绩创坛 2026 秋季创业营
│   └── 食刻-奇绩创坛申请表-2026秋.md     # 申请表逐题草稿（可直接复制粘贴）
└── 活动-S创2026/                      # 当前活动：S创2026
    └── 食刻-BP-S创2026版.md           # 可发送的 BP
```

## 使用流程

1. 先看 `通用/` 拿核心内容（产品介绍 / 核心信息母版）；
2. 到对应活动的文件夹取用或修改定制文案；
3. 报名新活动时：新建 `活动-XXX/` 文件夹，复制通用核心资料，按活动题目定制，平台特定内容（如云厂商方案）只写在该活动版本里。
