# 食刻 ShiKe · 商业计划书

**贴在冰箱上的 AI 食品扫描台**

> 食刻在场，不浪费每一份食材

## 一、执行摘要

食刻（ShiKe）是一台贴在冰箱上的 AI 食品扫描台：把食品放到镜头前扫一下，云端 AI 实时识别出品名与保质期，库存自动记账；屏幕、手机端和大屏随时告诉你"谁快过期、能做什么菜"。

我们以"对存量电器进行智能化+AI改造 + 零学习成本"切入，让每个家庭以最低成本体验智能家居，同时从源头减少食品浪费——这是全球每年 1/3 食物被浪费背后，每个家庭都能参与的解决方式。

项目已作为端到端可演示产品跑通：硬件已烧录、云端后端已上线、H5/大屏可用、3D 打印外壳完成。商业路径为 C 端"硬件 + 增值订阅"与 B 端"合规盘点 / 空间共创 SaaS"双线推进。

## 二、项目背景与起源

食刻由 4 位年轻女性创业者发起，我们在早期创业活动中相识组队，因共同的"冰箱食物浪费"痛点走到一起。

项目源于一个几乎每个家庭都有的场景：冰箱里总有被遗忘的食物——临期食品被忽略、重复购买、最后过期扔掉。在项目早期，我们从切身痛点出发，把方案从早期复杂构想收敛为"贴在冰箱上的扫描台"：一块单板（屏、触控、摄像头、音频全板载）+ 一个云端接口，端到端跑通了硬件烧录、云端 AI 识别、H5/大屏与 3D 打印外壳。

## 三、产品与服务

**产品形态**：贴在冰箱上的 AI 食品扫描台（硬件）+ 云端识别服务 + 手机 H5 / 大屏软件。

**核心链路**：扫（拍照）→ 认（云端视觉 AI）→ 记（库存 ±1）→ 显（屏幕 + H5 + 大屏）。

**核心功能**：

| 功能 | 说明 |
|---|---|
| 扫描入库 | AI 实时识别品名与保质期，扫一下自动记账 |
| 临期提醒 | 到期主动提醒，不再错过、不再浪费 |
| 库存管理 | 家庭/空间库存一目了然，多人实时同步 |
| 菜谱推荐 | 按现有库存推荐今日菜谱 |
| 营养分析 | 评估饮食均衡与营养摄入，给出改善建议 |
| 购物清单 | 根据库存与临期情况自动生成补货清单 |
| 家庭共享 | 多位成员实时同步、分工录入、通知提醒 |
| 浪费统计 | 月度过期/浪费数据汇总，直观展示节省与减量效果 |
| 过期处理建议 | 临期食材自动给出烹饪或处理建议，物尽其用 |
| 多端显示 | 设备屏幕 + 手机 H5 + 大屏，随时可看 |

**差异化**：对存量电器进行智能化+AI改造——不换冰箱、不手动录入，把食材管理压缩成"扫一下"；多端同步与共享能力，适配家庭、办公等多人共用的真实空间。

## 四、解决的社会问题

食品浪费是全球性议题，也是联合国可持续发展目标（SDG 12：负责任的消费和生产）的核心命题：

- 全球每年约 1/3 的食物被浪费；
- 中国年浪费食物超 1 亿吨，家庭冰箱保有量超 3 亿台；
- 核心痛点："放进去就忘"——临期遗忘、重复购买、过期浪费；
- 现有方案要么换智能冰箱（数千至上万元、门槛高），要么手动录入 App（繁琐、难坚持），都难以普及。

食刻把"减少浪费"从口号变成日常动作：扫一下自动记账、到期主动提醒、临期给出处理建议，让"不浪费"几乎不需要额外努力。

## 五、目标人群与共创场景

**核心人群**
- 注重健康与性价比的中国家庭，尤其是多口之家（老人/儿童同住）、大城市的独居单身人士、厨房新手与健身人群。

**延展与共创场景**
- **办公空间**：办公室共享冰箱/零食柜的临期管理与浪费减少，与办公空间运营方共创试点；
- **食堂 / 餐饮 / 药房**：合规盘点与台账管理；
- **社区与家庭用户共创**：以真实用户反馈持续打磨产品形态；
- **出海方向**：日本家庭（食品浪费意识强、包装日期规范，对食材管理需求明确）。

## 六、市场与机会

食品浪费是高频刚需痛点，但整机智能冰箱渗透率低、手动 App 留存难。"对存量电器进行智能化+AI改造"存在明确机会：

- 存量冰箱数量庞大，换机周期长，改造比替换更易普及；
- 智能家居渗透率持续提升，家庭小型化与独居人群增加；
- 食品健康与营养管理意识增强，与菜谱、营养等增值服务天然衔接。

## 七、商业模式

双线推进，相互验证：

1. **C 端：硬件 + 增值订阅**
   - 硬件按成本合理定价，覆盖入门体验；
   - 订阅服务覆盖云端 AI 识别、营养分析、多家庭共享、历史数据等。
2. **B 端：合规盘点 / 空间共创 SaaS**
   - 面向食堂、餐饮、药房提供识别盘点与台账服务；
   - 面向办公空间提供共享冰箱/零食柜管理方案，按空间/门店订阅。
3. **技术合作通道**：向家电厂商及空间运营方开放识别技术合作。
