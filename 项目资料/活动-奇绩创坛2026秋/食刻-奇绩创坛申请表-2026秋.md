## 2. 创业想法

**你的公司要做什么？**（合伙人最先看的一题，务必一句话讲清）
食刻要做"存量家电的 AI 升级"：先做贴在冰箱上的 AI 食品扫描台，让 3 亿台旧冰箱花几百块就能拥有"食材识别 + 临期提醒 + 库存管理"。内核是一套食品视觉识别与效期管理能力，未来复用到药盒效期、零食柜、食堂/药店盘点，并出海日本。

**你们要解决什么问题？**
"放进去就忘"——冰箱里的食物临期被忽略、重复购买、最后过期扔掉。全球每年约 1/3 食物被浪费，中国年浪费超 1 亿吨。现有方案只有两个：换智能冰箱（数千至上万元，只覆盖每年约 7-8% 的换机家庭），或手动录入 App（繁琐、难坚持）。食刻把"减少浪费"变成几乎零成本的日常动作。

**为什么现在做？**
1. 视觉大模型让"食品识别 + 保质期 OCR"的准确率首次跨过可用门槛，单次调用成本降到几分钱；
2. 存量冰箱约 3.24 亿台、换机周期长，智能冰箱内置功能结构性覆盖不到存量市场（智能冰箱市场规模仅约占冰箱大盘 2%），外挂扫描台是唯一能覆盖存量的形态；
3. 家庭小型化、独居增多，健康饮食与"反浪费"意识上升，时机窗口打开。

> 佐证：博世 2026 年 3 月关闭冰箱内置摄像头"远程查看"功能，官方承认市场需求不足——恰好印证"内置不等于需求"，外挂形态的空白真实存在。

**目前进展如何？**
- 端到端可演示原型已跑通：硬件扫描台（T5-E1 单板：屏 / 触控 / 摄像头 / 音频板载）完成烧录，3D 打印外壳完成（米白机身 + 红屋顶 + 磁吸后盖）；
- 云端后端已上线：11 个 API / 15 张表，AI 识别品名 + 保质期可用，低置信不入库；
- H5 手机端与大屏 Web 已上线可在线体验，代码开源（GitHub）；
- 已有真实扫描数据积累；识别与日期提取准确率是当前最大短板【建议补一句：已完成 X 张真实商品样本测试，识别率 Y%】；
- 下一步（30 天）：100 人种子家庭用户测试，识别率目标 ≥90%；随后众筹验证付费（2,000-5,000 台，回笼约 150 万元现金流）。

**你们有什么独特的见解？**
"食材识别"被巨头做成高端智能冰箱的溢价功能（识别模组硬件成本约 45 元，消费者却为它支付近千元溢价），但内置只覆盖每年换新家庭中的一小部分——90%+ 家庭未来几年继续用旧冰箱，这是巨头的结构性盲区。真正值钱的不是"识别"本身，而是保质期自动读取和临期提醒的日常服务；外挂扫描台 + 扫一下就记账，比换冰箱和手动 App 都更接近家庭日常。我们把它做成百元级、零学习成本的"旧冰箱升级"。

**目标用户是谁？**
- 首发：注重健康与性价比的中国家庭——多口之家（老人 / 儿童同住）、大城市独居单身、厨房新手与健身人群；渠道先用"子女给父母买"的银发关怀故事（异地子女远程看见父母冰箱，情感溢价高）。
- 第二曲线：食堂 / 餐饮 / 药房效期台账合规盘点、办公空间共享冰箱。
- 出海：日本首发（家庭端年浪费 224 万吨、包装日期体系规范、无外挂扫描台竞品），Makuake → Amazon Japan（SwitchBot 已验证路径）。

**你们如何获取用户？**
冷启动：100 台种子用户免费送，换真实使用数据与口碑；小红书 / 抖音以"翻出 3 年前的罐头""外婆的冰箱""独居女孩的冰箱"等情绪选题做 KOC 种草；小米有品 / 京东众筹 2,000-5,000 台验证付费与现金流。规模化：电商自营 + 分销，与家电卖场合作"旧冰箱升级"专区；B 端先 1 个城市 30-50 家店验证 ROI 再复制；海外 Makuake → Amazon Japan。

**竞争对手？你们如何差异化？**
- 整机智能冰箱（海尔 AI 之眼 / 美的 / 三星）：只覆盖换机家庭里的高端小部分，识别溢价近千元；博世已关停内置摄像头功能，"内置不等于需求"。
- 手动录入 App（摆烂冰箱、NoWaste 等）：录入繁琐、难以坚持，留存差。
- 海外同类：美国 Ovie 开发 5 年后失败——教训是只讲环保故事撑不起付费，食刻的卖点排序为"省钱 > 省时间 > 健康 > 环保"，先算"每月少扔 50 元食物"的账，再谈社会价值。

食刻的差异化：存量冰箱外挂（巨头到不了）+ 扫一下零录入（App 做不到）+ 家庭共享多端（适合多人家庭）+ 百元级价格。

**商业模式？**
C 端：硬件 299 元（量产 BOM 目标 72-110 元，硬件毛利约 70%）+ 食刻云 Pro 订阅 99 元/年（临期推送、菜谱推荐、家庭共享、营养报告；首年免费送）；B 端：效期台账 SaaS 299-999 元/年/门店；技术授权给家电厂商为合作 / 退出通道。单用户 3 年毛利约 180-200 元，LTV/CAC ≥ 3。

**目前收入 / 数据**：【暂无营收；如有种子用户、众筹、预售、媒体报道可补充】公司主体：【未注册 / 注册中____】

**有什么大多数人都不同意、但你认为是对的观点？**
1. 家庭食材管理不需要"换智能冰箱"，也不需要"每天打开 App 录入"——它应该像门铃一样贴在你本来就有的东西上，扫一下就完成。未来几年只有约 7-8% 的家庭会换冰箱，真正的机会在 3 亿台存量上做外挂升级。
2. 巨头把食材识别做成高端冰箱的付费溢价，但识别硬件成本只要几十块钱——这个功能注定"白菜化"。赢家不是卖硬件的，而是拥有家庭食材数据、把"保质期提醒"做成高频服务的人。

**创业者的其他想法？**
同一内核可复用的两个方向：① 药盒效期管理（老人用药过期提醒，客单价与情感溢价更高）；② 商用效期台账 SaaS（餐饮 / 药房合规盘点，付费意愿最强）。若 C 端验证不达预期，可快速转向 B 端或识别技术授权，内核不变。
