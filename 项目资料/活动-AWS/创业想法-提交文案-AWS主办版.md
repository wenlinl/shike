## 产品概念

食刻（ShiKe）是一台贴在冰箱上的 AI 食品扫描台：把食品拿到镜头前扫一下，云端视觉 AI 实时识别出品名与保质期，库存自动加减，屏幕、手机端和大屏随时告诉你“谁快过期、能做什么菜”。

产品不做“换整台智能冰箱”的昂贵路线，而是“对存量电器进行智能化+AI改造 + 零学习成本”：不换设备、不手动录入，把食材管理压缩成“扫一下”这一个动作，让每个家庭以最低成本体验智能家居，端到端链路为 扫（拍照）→ 认（云端视觉 AI）→ 记（库存 ±1）→ 显（设备屏幕 + 手机 H5 + 大屏）。当前已作为可演示产品跑通：硬件已烧录、后端已上线、H5/大屏可用、3D 打印外壳完成。

## 解决什么问题

全球每年约 1/3 的食物被浪费，中国年浪费超过 1 亿吨，家庭冰箱保有量超 3 亿台。核心痛点是“放进去就忘”——临期食品被遗忘、重复购买、过期浪费。

现有方案要么换整台智能冰箱（数千至上万元、渗透率低），要么靠手动录入 App（繁琐、难以坚持）。食刻通过“扫码入库 + AI 识别保质期 + 临期主动提醒 + 库存菜谱推荐”形成闭环，减少浪费、吃得健康，并让家庭以最低成本迈入智能家居；也顺带解决“今天做什么菜”的日常决策。

## 目标用户

- 第一阶段：注重健康与性价比的中国家庭，重点是老人/儿童同住的多口之家、厨房新手与健身人群。硬件 BOM 成本 ¥70–90，把体验门槛降到“贴上去、扫一下”。
- 第二阶段：出海日本——日本食品浪费社会共识最强、包装日期体系规范、暂无外挂扫描台竞品；首发部署东京区域，满足日本个人信息保护法（APPI）数据合规。
- 第三阶段：延伸 B 端，面向食堂、餐饮、药房做合规盘点 SaaS，验证单品后复制到企业厨房场景。

## 如何使用亚马逊云科技技术

- **存储**：Amazon S3 存储扫描图片，按家庭/设备分区，为后续模型迭代沉淀数据资产；
- **数据库**：Amazon DynamoDB 支撑高频库存读写（扫码 ±1、多端实时同步），Amazon RDS 承载家庭、成员、菜谱等关系型业务数据；
- **AI 能力**：Amazon Bedrock 提供食品识别与保质期日期 OCR，Amazon Rekognition 做低成本图像标签校验，低置信结果不入库，保证录入准确率；
- **接入层**：Amazon API Gateway + AWS Lambda 支撑扫描请求的无服务器接入，按量计费、秒级扩容；Amazon Cognito 负责家庭与设备鉴权，一台设备对应一个家庭空间；
- **分发与部署**：Amazon CloudFront 加速 H5 手机端与大屏 Web，后端容器化部署于 Amazon ECS/Fargate，实现全球低延迟访问；
- **合规与扩展**：首发 ap-northeast-1（东京）满足日本 APPI 合规，架构按多区域预留，为欧美市场扩展做好准备。

一句话总结：食刻用“贴冰箱的 AI 扫描台 + 云端识别记账”，让每个家庭以最低成本体验智能家居、减少浪费、吃得健康，并以 AWS 全球化基础设施支撑从中国家庭到日本、欧美的出海路径。
