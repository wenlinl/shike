# 食刻 ShiKe · 项目介绍

> 贴在冰箱上的 AI 食品扫描台
> Slogan：**食刻在场，不浪费每一份食材**

## 项目概览

| 项 | 内容 |
|---|---|
| 项目名称 | 食刻（ShiKe） |
| 一句话定位 | 贴在冰箱上的 AI 食品扫描台：扫一下就知道是什么、能放多久、该怎么办 |
| 核心理念 | 对存量电器进行智能化+AI改造：不换冰箱，以最小成本让现有家电变聪明 |
| 核心链路 | 扫（拍照）→ 认（云端视觉 AI）→ 记（库存 ±1）→ 显（屏幕 + 手机 H5 + 大屏） |
| 项目阶段 | 端到端可演示原型已跑通（硬件 + 云端 + 软件全链路） |
| 项目背景 | 源自团队成员共同的冰箱食物浪费痛点 |

## 项目起源

食刻由 4 位年轻女性创业者发起，我们在早期创业活动中相识组队。项目源于一个几乎每个家庭都有的痛点："冰箱里总有被遗忘的食物"。

在项目早期，我们完成了一次关键方案收敛：从早期依赖稀缺物料、链路复杂的"随身陪伴"构想，收敛为"贴在冰箱上的扫描台"——一块单板（屏、触控、摄像头、音频全板载）+ 一个云端接口，把不确定性压缩到最小，并端到端跑通：硬件烧录、云端 AI 识别、H5/大屏、3D 打印外壳全部完成。

## 产品是什么

食刻是一台贴在冰箱上的 AI 食品扫描台：把食品放到镜头前扫一下，云端 AI 实时识别出品名与保质期，库存自动记账；屏幕、手机端和大屏随时告诉你"谁快过期、能做什么菜"。

### 核心功能

| 功能 | 说明 |
|---|---|
| 扫描入库 | AI 实时识别品名与保质期，扫一下自动记账 |
| 临期提醒 | 到期主动提醒，不再错过、不再浪费 |
| 库存管理 | 家庭库存一目了然，多人实时同步 |
| 菜谱推荐 | 按现有库存推荐今日菜谱 |
| 营养分析 | 评估饮食均衡与营养摄入，给出改善建议 |
| 购物清单 | 根据库存与临期情况自动生成补货清单 |
| 家庭共享 | 多位成员实时同步、分工录入、通知提醒 |
| 浪费统计 | 月度过期/浪费数据汇总，直观展示节省与减量效果 |
| 过期处理建议 | 临期食材自动给出烹饪或处理建议，物尽其用 |
| 多端显示 | 设备屏幕 + 手机 H5 + 大屏，随时可看 |

## 解决什么问题

- 冰箱食物"放进去就忘"：临期遗忘、重复购买、过期浪费；
- 全球每年约 1/3 食物被浪费，中国年浪费超 1 亿吨，家庭冰箱保有量超 3 亿台；
- 现有方案要么换智能冰箱（数千至上万元、门槛高），要么手动录入 App（繁琐、难坚持）；
- 食刻以"对存量电器进行智能化+AI改造 + 零学习成本"切入，让每个家庭以最低成本体验智能家居。

## 目标人群

- 核心人群：注重健康与性价比的中国家庭，尤其是多口之家（老人/儿童同住）、大城市的独居单身人士、厨房新手与健身人群；
- 延展人群：食堂 / 餐饮 / 药房等 B 端客户（合规盘点需求）；
- 出海方向：日本家庭（食品浪费意识强、包装日期规范，对食材管理需求明确）。

## 当前进展（已跑通）

- 已有可演示原型机（硬件扫描台 + 3D 打印外壳）；
- 硬件扫描台已完成并烧录（T5-E1 单板，屏/触控/摄像头/音频板载）；
- 云端后端已上线，11 个 API / 15 张表，AI 识别可用；
- H5 手机端与大屏 Web 已上线，可在线体验；
- 3D 打印外壳完成（米白机身 + 红屋顶 + 磁吸后盖）。

## 市场与价值

**市场**：食品浪费是全球性难题。中国年浪费超 1 亿吨，家庭冰箱保有量超 3 亿台；"食材管理"是高频刚需场景，但现有智能冰箱渗透率低、手动 App 留存难，对存量电器进行智能化+AI改造存在明确机会。

**价值**：
- 对家庭：减少浪费、健康饮食，以最低成本体验智能家居；
- 对合作方：已跑通"硬件 + 云端 AI + 多端产品"全链路，可开放硬件方案与云端接口，共同落地 B 端场景。

## 团队

4 位年轻女性创业者，职业背景各不相同、优势互补；在早期创业活动中相识组队，从原型做到今天可演示、可落地的完整产品。我们相信女性视角更懂家庭饮食场景，团队小而高效，崇尚快速验证与真实反馈。

## 未来规划

- **一键补货**：联动生鲜电商/商超，库存告急时一键下单补货；
- **B 端盘点**：面向食堂/餐饮/药房提供合规盘点 SaaS；
- **磁吸门版 v2 硬件**：更小更便宜（BOM ¥70–90），可贴门内/门外两用；
- **门内连续扫描**：批量采购一次过件、关门汇总确认；
- **边缘识别 + 离线兜底**：已知食品本地秒级识别，断网也能记账；
- **出海日本首发**：满足当地合规，逐步拓展欧美市场。
