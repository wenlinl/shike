# 食刻 ShiKe · 商业计划书

> 版本：2026-08 · 供路演 / 比赛 / 融资参考
> 说明：外部提交前请核对【待补充】项；核心数据以团队口径为准。

## 一、执行摘要

食刻（ShiKe）是一台贴在冰箱上的 AI 食品扫描台：食品放到镜头前扫一下，云端 AI 实时识别出品名与保质期，库存自动记账；屏幕、手机端和大屏随时提醒"谁快过期、能做什么菜"。

项目以"对存量电器进行智能化+AI改造 + 零学习成本"切入，让每个家庭以最低成本体验智能家居。当前端到端原型已跑通（硬件烧录、云端后端、H5/大屏、3D 外壳），商业路径为 C 端"硬件 + 增值订阅"与 B 端"合规盘点 SaaS"双线推进。

## 二、产品与服务

**产品形态**：贴在冰箱上的 AI 食品扫描台（硬件）+ 云端识别服务 + 手机 H5 / 大屏软件。

**核心链路**：扫（拍照）→ 认（云端视觉 AI）→ 记（库存 ±1）→ 显（屏幕 + H5 + 大屏）。

**核心功能**：扫描入库、临期提醒、库存管理、菜谱推荐、营养分析、购物清单、家庭共享、浪费统计、过期处理建议、多端显示。

**差异化**：对存量电器进行智能化+AI改造——不换冰箱、不手动录入，把食材管理压缩成"扫一下"；家庭共享与多端同步，适合多人家庭。

## 三、市场分析

**问题**：全球每年约 1/3 食物被浪费，中国年浪费超 1 亿吨，家庭冰箱保有量超 3 亿台。核心痛点是"放进去就忘"——临期遗忘、重复购买、过期浪费。

**趋势**：智能家居渗透率持续提升；食品健康与营养管理意识增强；家庭小型化、独居人群增加。

**机会**：存量冰箱数量庞大，换机周期长，"改造而非替换"是更低门槛的切入方式。

## 四、竞争分析

| 方案 | 代表 | 局限 | 食刻的差异 |
|---|---|---|---|
| 整机智能冰箱 | 海尔/美的/三星等 AI 冰箱 | 成本数千至上万元、渗透率低 | 存量改造、百元级成本 |
| 手动录入 App | 摆烂冰箱、NoWaste 等 | 录入繁琐、难以坚持 | 扫一下自动记账、零学习成本 |
| 食刻 | — | 识别准确率仍需提升、商业化刚起步 | 硬件+云端+多端全链路、家庭共享 |

**切入楔子**：不与巨头正面竞争，以"对存量电器进行智能化+AI改造 + 零学习成本 + 家庭共享"切入，先服务 C 端家庭，再延伸 B 端。

## 五、目标用户与市场策略

- **第一阶段（C 端）**：注重健康与性价比的中国家庭，重点是多口之家、大城市的独居单身人士、厨房新手与健身人群；通过性价比硬件 + 零学习成本降低门槛；
- **第二阶段（B 端）**：食堂 / 餐饮 / 药房合规盘点 SaaS，以轻资产方式验证付费意愿；
- **第三阶段（出海）**：日本首发（食品浪费共识强、包装日期规范、无外挂扫描台竞品），再拓展欧美。

## 六、商业模式

建议采用双线模式（定价与细节待团队确认）：

1. **C 端：硬件 + 增值订阅**——硬件按成本合理定价，订阅覆盖云端 AI 识别、营养分析、多家庭共享、历史数据等增值服务；
2. **B 端：合规盘点 SaaS**——面向食堂/餐饮/药房提供识别盘点与台账服务，按席位数/门店数订阅；
3. **退出通道**：向家电厂商标识识别技术授权，保留合作与退出选项。

【待补充】各产品线定价、硬件成本与毛利、订阅价格。

## 七、当前进展与验证

**已跑通**：硬件烧录（T5-E1 单板）、云端后端上线（11 个 API / 15 张表）、AI 识别可用、H5/大屏可用、3D 打印外壳完成、已有可演示原型机。

**商业化准备度自评**：硬件/固件完成度高，视觉识别准确率与日期提取是当前最大短板，商业化前需把识别率提升到 ≥90% 并通过真实用户测试验证。

**下一步（30 天）**：招募约 100 名真实家庭用户测试，迭代识别准确率与临期提醒推送，再决定 C 端众筹或 B 端样板客户路线。

## 八、技术方案与云架构

**当前**：T5-E1 单板（屏/触控/摄像头/音频板载）+ 云端视觉 AI + SQLite 数据库，后端容器化部署。

**规模化规划**：
- 存储与数据库：扫描图片对象存储 + 高频库存读写数据库 + 关系型业务库；
- AI 能力：食品识别与保质期 OCR，低置信不入库，持续用真实数据迭代；
- 接入层：无服务器 API 承接扫描请求，家庭/设备鉴权，内容分发加速多端；
- 合规与出海：首发区域满足当地数据合规（如日本 APPI），架构按多区域扩展预留。

> 注：云厂商选择按活动/合作方要求而定，核心方案与厂商解耦。

## 九、团队

4 位年轻女性创业者，职业背景各不相同、优势互补；在早期创业活动中相识组队，从原型做到可演示、可落地的完整产品。团队小而高效，覆盖硬件、云端、软件与产品叙事，崇尚快速验证与真实反馈。
