# 食刻 ShiKe · 产品介绍

> 贴在冰箱上的 AI 食品扫描台
> Slogan：**食刻在场，不浪费每一份食材**

## 一句话介绍

食刻是一台贴在冰箱上的 AI 食品扫描台：把食品放到镜头前扫一下，云端 AI 实时识别出品名与保质期，库存自动记账；屏幕、手机端随时告诉你"谁快过期、能做什么菜"。

## 解决什么问题

- 冰箱里的食物"放进去就忘"——临期食品被遗忘、重复购买、过期浪费；
- 全球每年约 1/3 的食物被浪费，中国年浪费超过 1 亿吨；
- 现有方案要么换整台智能冰箱（数千至上万元、门槛高），要么手动录入 App（繁琐、难坚持）。

## 我们的做法

- **对存量电器进行智能化+AI改造**：不换冰箱，直接贴/吸在现有冰箱上，让现有家电变聪明；
- **零学习成本**：扫一下，自动识别、自动记账；
- **最低成本体验智能家居**：硬件成本约百元级，人人都用得起。

## 怎么用

1. 买完菜，把食物放到镜头前扫一下；
2. 云端 AI 实时识别品名 + 保质期，库存自动 ±1；
3. 随时查看：谁快过期、该买什么、能做什么菜。

## 核心功能

| 功能 | 说明 |
|---|---|
| 扫描入库 | AI 识别食品品名与保质期，扫一下自动记账 |
| 临期提醒 | 到期主动提醒，不再错过、不再浪费 |
| 库存管理 | 家庭库存一目了然，多人共享实时同步 |
| 菜谱推荐 | 根据现有库存推荐今日菜谱 |
| 营养分析 | 评估饮食均衡与营养摄入，给出改善建议 |
| 购物清单 | 根据库存与临期情况自动生成补货清单 |
| 家庭共享 | 多位成员实时同步、分工录入、通知提醒 |
| 浪费统计 | 月度过期/浪费数据汇总，直观展示节省与减量效果 |
| 过期处理建议 | 临期食材自动给出烹饪或处理建议，物尽其用 |
| 多端同步 | 设备屏幕 + 手机 H5 + 大屏，随时可看 |

## 目标人群

- 核心人群：注重健康与性价比的中国家庭，尤其是多口之家（老人/儿童同住）、大城市的独居单身人士、厨房新手与健身人群；
- 延展人群：食堂 / 餐饮 / 药房等 B 端客户（合规盘点需求）；
- 出海方向：日本家庭（食品浪费意识强、包装日期规范）。

## 当前进展（已跑通）

- 已有可演示原型机（硬件扫描台 + 3D 打印外壳）；
- 硬件扫描台已完成并烧录，3D 打印外壳完成（米白机身 + 红屋顶 + 磁吸后盖）；
- 云端后端已上线，AI 识别可用；
- H5 手机端与大屏 Web 已上线，可在线体验。

## 未来优化方向

- 一键补货：联动生鲜电商/商超，库存告急时一键下单补货；
- B 端盘点：面向食堂 / 餐饮 / 药房提供合规盘点 SaaS。
