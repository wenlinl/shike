### 2.2 极简 JSON 解析（不引入第三方库）

```c
// 响应形如：{"data":[{"name":"牛奶","daysLeft":2}, ...]}
// 用逐字符扫描提取 name 与 daysLeft（项目无 json 库时够用）
static int parse_items(const char* json, char names[][32], int days[], int max, int* count) {
    *count = 0;
    const char* p = json;
    while ((p = strstr(p, "\"name\"")) != NULL && *count < max) {
        p = strchr(p, ':') + 1;                 // 跳过 "name":
        while (*p == '"') p++;                  // 跳引号
        int n = 0;
        while (*p && *p != '"' && n < 31) names[*count][n++] = *p++;
        names[*count][n] = '\0';

        const char* d = strstr(p, "\"daysLeft\"");
        if (d) days[*count] = atoi(strchr(d, ':') + 1);
        (*count)++;
    }
    return *count > 0 ? 0 : -1;
}
```

### 2.3 屏幕显示（点阵字库，16×16）

```c
// 现有工程已有 HZK16 显示函数（如 lcd_draw_text），直接复用：
static void ui_show_inventory(char names[][32], int days[], int count) {
    lcd_clear(WHITE);
    for (int i = 0; i < count && i < 8; i++) {
        char line[48];
        snprintf(line, sizeof(line), "%s  剩%d天", names[i], days[i]);
        lcd_draw_text(0, 20 + i * 20, line, BLACK);   // 每行 20px，8 行 160px
    }
    lcd_refresh();
}
```

## 3. 冲刺版注意

1. **先做库存页**（D5）：GET /api/items + 列表显示，验证 HTTPS GET 与 JSON 解析；
2. **再做汇总页**（D6）：触控按钮 + 确认动作；后端"待确认"接口可先用演示数据；
3. **点阵字库约束**：中文用 HZK16 16×16，界面文案限 GB2312 字符集（现有工程已有）；
4. 双模组同步走云端：内模组上传 → shike.live → T5-E1 GET 刷新（无需直连）。
