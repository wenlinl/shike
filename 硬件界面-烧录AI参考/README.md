# 食刻 · 硬件界面参考（给烧录 AI）

> 目标板：T5-E1（SPARKLEIOT T5AI DEV）｜屏幕：ST7789 **240×320** 触控彩屏（SPI0）｜摄像头：板载 GC2145 DVP 640×480
> 用途：作为「食刻」固件 UI 的实现参考。每个界面一个独立 HTML 文件，**页面本体即为 240×320（与硬件屏幕等大，无外围页面）**；右上角 **i** 角标可切换查看实现说明浮层（状态、尺寸、色值、alpha、API 对应）。

## 界面清单与固件状态映射

| 文件 | 固件状态 | 触发条件 | 核心动作 |
|---|---|---|---|
| `01-待机页.html` | IDLE | 开机/完成后 | 显示临期提醒；点【放入/取出】进入拍照 |
| `02-拍照倒计时.html` | SCAN | 选择放入/取出后 | 3→2→1 半透明大数字倒计时，归零自动拍照上传 |
| `03-识别中.html` | RECOGNIZING | 照片已上传 | 等待解析，超时 15s 进失败页 |
| `04-识别结果-放入.html` | RESULT(in) | 识别成功 | 显示品名/时间/保质期/建议容器；确认后库存 +1 |
| `05-识别结果-取出.html` | RESULT(out) | 识别成功（取出模式） | 同上，确认后库存 −1 |
| `06-识别失败-重拍.html` | LOW_CONF | 置信度 < 0.5 或品名为空 | 不写库存，提示重拍 |
| `07-网络错误.html` | NET_FAIL | 上传失败/超时 | 保留动作，可重试 |
| `08-断网离线.html` | OFFLINE | 断网 | 显示本地最近库存与提醒，禁用扫描 |
| `09-启动页.html` | BOOT | 上电 | 品牌展示 + 连接云端，2–3s 后进 IDLE 或 OFFLINE |

## 交互与验收对照（固件需求 §5）

- 待机页两个大按钮：**放入**（红实心）、**取出**（白底红描边），触控目标 ≥ 80px 高；
- 倒计时数字：**占屏约一半（建议 120×160 居中），透明度约 55%**，能看到背后实时画面；归零自动抓帧 + “咔嚓”音效；
- 上传 `POST https://shike.live/api/scan`（multipart：image/deviceId/action/container/timestamp），超时 15s；
- 结果页显示：品名、当天日期时间、保质期/到期日、建议容器（可切换，5 个容器 chips）；
- 低置信（<0.5）不写库存；网络失败可重试且不丢动作；断网显示本地缓存并禁用扫描；
- 设备端不持有任何 API Key。

## 使用方式

直接把这整个文件夹（或单个界面 HTML）交给硬件烧录 AI；每个文件的 `.screen` 区即 240×320 的 UI，文件下方「实现说明」区是给固件的结构化提示。同目录另有每个界面的 PNG 预览图与 `index-总览.html` 一览页。
