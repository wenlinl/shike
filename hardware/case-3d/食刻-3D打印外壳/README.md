# 食刻 · 冰箱贴智能屏 3D 打印外壳

> 状态（2026-08-23）：本外壳为 **HW-v0 概念 demo 配套**（T5-E1 单板扫描台：摄像头口 + 主板竖装 + 磁吸后盖）。HW-v1 双模组分体形态下 T5-E1 转为**外置平板**（不再使用板载摄像头扫码，识别由内模组完成），本外壳的摄像头口 / 按键 / 喇叭开孔需在 v1 外壳设计中确认沿用或改版（**待定**）；最新硬件逻辑以[设计基线 v4.1](../../docs/02-硬件/设计基线-硬件逻辑梳理.md)为准。

按产品示意图做的**扁平小房子造型**：米白机身 + 红色山墙屋顶（在机身顶部、
左坡带烟囱）、机身正面上部正中间 **17×17mm 方形摄像头口**、正面下方大屏幕窗口、
底部正中间充电口（12mm 宽、距底 17mm 高）、右侧按键与喇叭孔、背面磁吸后盖。

主板竖装：**高 87mm × 宽 50mm × 厚 20mm**，屏幕窗口 **48mm 宽 × 67mm 高**。

## 主板信息（已确认）

- 型号：**T5-E1（SPARKLEIOT T5AI DEV）**，TuyaOpen 平台 `t5ai`
- 实测：**87 × 50 × 20 mm**（长×宽×厚，竖装），屏幕 **67 × 48 mm**
- 板载：ST7789 240×320 触控彩屏、CST816X 触控、GC2145 摄像头、
  内置音频、microSD、按键 GPIO8、USB 供电

## 尺寸（当前模型）

- 机身：66 × 107 × 26.8 mm（主板 50×87×20 + 壁厚 + 后盖）；
  红色屋顶在机身顶部之上（屋脊高出 8.5mm），整机总高约 115.5mm
- 屏幕窗口：48 × 67 mm（居中，比屏大 1.5mm 间隙）
- 摄像头口：17×17mm 方形，正中间（x=0，y=44），背后有竖直通道连通板载镜头
- 充电口：底部正中间，12mm 宽、从底部往上 17mm 高的开口（USB-C 插头从下方插入）
- 螺丝：M2×6 自攻 ×4；磁铁：Ø10×1.6mm N52 ×4；主板与后盖间建议垫 1~2mm 泡棉

## 装配

1. 前壳正面朝下打印（米白），屋顶件平放打印（红色）；后盖平放打印（米白）
2. 屋顶件放到机身顶部贴 3M 双面胶或热熔胶（屋顶底边正好落在机身上缘）
3. 后盖沉孔放入 4 颗磁铁（注意 4 颗极性一致）
4. 主板放进机身内腔：屏幕对准窗口，摄像头镜头朝上/朝前对准通道
5. 盖上后盖，M2×6 自攻螺丝 ×4 锁紧；USB 线从底部开口穿出

> 板载摄像头镜头请对着 17×17 方孔确认，如位置有偏差，改 `CFG` 里的
> `cam_y` / `cam_win_y` 重新生成即可。

## 重新生成

```bash
python3 build_case.py --part all --res 0.45   # 重新生成全部 STL
python3 render_ray.py                         # 重新渲染预览图
```

尺寸全部集中在 `build_case.py` 顶部 `CFG`（主板、屏幕、摄像头、USB、按键、
屋顶三角形顶点、烟囱位置等均为参数）。

## Bambu Studio 使用步骤

1. 在 Windows 电脑从 [Bambu Lab 官网](https://bambulab.com/zh-cn/bambu-studio)
   下载安装 Bambu Studio；
2. 新建工程 → 导入 `食刻-前壳.stl`、`食刻-屋顶-红色.stl`、`食刻-后盖.stl`；
3. 摆放：前壳**正面朝下**（屏幕窗口贴热床），后盖平放，屋顶件倒扣/平放均可；
4. 材料建议：PLA / PETG，层高 0.2mm；
5. 分色：屋顶件直接用红色耗材打印，机身/后盖用米白耗材——天然两色，
   无需 AMS 上色；屏幕边框如需红色，可用油漆笔手涂；
6. 切片后检查：无悬垂大角度，一般不需要支撑；屋顶件较薄（2.2mm），
   打印后注意别掰断；
7. 打印完成后按上面“装配”步骤组装。
