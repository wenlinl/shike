## 外观与结构

- 黑色 PCB，正面丝印标注 3 个引脚：`S`、`-`（中间为 VCC）；
- 中央为金属外壳一体化红外接收头（VS1838B 系列），带黑色红外接收窗口，接收 38kHz 红外信号；
- 板载 1kΩ 贴片电阻（R1）与电源指示灯；
- 3P 2.54mm 直插排针；2 个金属化安装孔（可螺丝 / 铜柱固定）。

## 接口 / 引脚说明

| 引脚 | 说明 |
|---|---|
| - | GND 地线 |
| VCC（中间引脚） | 电源正极，接 3.3V（也支持 5V，项目优先 3.3V） |
| S | 信号输出（解调后的红外编码信号）——接普通 GPIO |

## 工作原理

- 电视 / 家电遥控器按下按键，发出 38kHz 红外光；
- 模块的接收头接收并解调，把编码信号通过 S 引脚传给 ESP32；
- 单片机解析编码，识别按了哪个按键。

## 接线示例（XIAO ESP32‑S3）

| 模块引脚 | XIAO ESP32‑S3 |
|---|---|
| - | GND |
| VCC | 3V3（也支持 5V，项目优先 3.3V） |
| S | 普通 GPIO（如 D0） |

## 使用方法（食材项目）

- 用普通电视遥控器当作外部按键，不用额外硬件按钮；
- 遥控器按键触发拍照、触发识别食材。

## ⚠️ 小坑

1. **不能强光直射**：太阳光强的时候会干扰接收；
2. 通信库一般用 `IRremote`：ESP32 版本要下载**适配 ESP32 的分支**，普通 Arduino 库直接编译会报错；
3. 本模块只接收红外，**不能发射**，发射需要另外的红外 LED 模块。
