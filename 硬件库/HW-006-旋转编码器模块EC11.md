## 外观与结构

- 黑色 PCB，丝印标注 5 个引脚：`CLK`、`DT`、`SW`、`+`、`GND`；
- 中央为金属外壳 EC11 编码器，银色六角螺母 + 垫圈固定，顶部灰色旋钮帽，旋转有“咔哒”档位感；
- 顶部 5P 2.54mm 直插排针；右侧 2 个金属化安装孔（可螺丝 / 铜柱固定）；
- 板上还可见 1 个向上箭头（^）丝印标识。

## 接口 / 引脚说明

| 引脚 | 说明 |
|---|---|
| CLK | 旋转信号 A（时钟脉冲）——接普通 GPIO |
| DT | 旋转信号 B（相位差脉冲）——接普通 GPIO，与 CLK 配合判断方向与步数 |
| SW | 按键信号——按下旋钮时触发，接普通 GPIO |
| + | 电源正极，接 3.3V |
| GND | 地线，接板子 GND |

## 工作原理

- **旋转**：顺时针 / 逆时针转动时，CLK、DT 输出相位差（正交）脉冲，单片机根据两路脉冲相位先后判断转动方向、累计转动步数；可以无限旋转，没有限位；
- **按键**：SW 引脚按下旋钮即触发，等效一个独立按键。

## 接线示例（XIAO ESP32-S3）

| 编码器模块 | XIAO ESP32-S3 |
|---|---|
| GND | GND |
| + | 3V3 |
| CLK | 普通 GPIO（如 D0） |
| DT | 普通 GPIO（如 D1） |
| SW | 普通 GPIO（如 D2，按下检测） |

## 使用方法（食材项目）

- 菜单选择：切换食材列表、调节参数；
- 按下旋钮确认；
- 旋转翻页浏览识别出来的食材。

## ⚠️ 注意区分

1. **电位器**：只能转一圈 / 半圈，输出模拟电压（ADC 读取）；
2. **EC11 编码器**：无限转圈，输出数字脉冲（正交信号），**不使用 ADC**；
3. ESP32 推荐使用 `Encoder` 库读取旋转；
4. SW 按键记得做消抖处理。
