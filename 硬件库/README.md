# 硬件库（比赛带回硬件登记）

> 用途：登记比赛 / 活动结束后带回的硬件，统一编号、照片归档、状态跟踪，方便后续复用到项目（如食刻样机）或查阅。
> 建立：2026-08-21

## 登记规则

1. **编号递增**：从 `HW-001` 开始，每件硬件一个编号（`HW-XXX`），不重复；
2. **一硬件一详情页**：每个硬件创建 `HW-XXX-硬件名称.md` 详情页，并在 [硬件清单](./硬件清单.md) 总表登记一行；
3. **照片归档**：照片放入 `图片/` 目录，命名 `HW-XXX-硬件名称-视角.jpg`（如 `HW-001-红绿双色LED模块-正面.jpg`）；至少保留正面、背面各一张；
4. **状态维护**：硬件转借、损坏、用尽时，同步更新总表状态与详情页；
5. **新硬件登记**：复制 [硬件条目模板](./硬件条目模板.md) 填写，照片拍好后按规则命名放入 `图片/`。

## 目录结构

```text
硬件库/
├── README.md                 # 本说明
├── 硬件清单.md                 # 总清单（最新状态一览）
├── HW-XXX-硬件名称.md          # 单件硬件详情
├── 硬件条目模板.md             # 新增硬件时复制此模板
└── 图片/
    └── HW-XXX-硬件名称-视角.jpg
```

## 必填字段

| 字段 | 说明 |
|---|---|
| 编号 | `HW-XXX`，唯一 |
| 名称 | 硬件通俗名称 |
| 型号 / 规格 | 芯片 / 封装 / 电压 / 接口等关键参数 |
| 数量 | 该件硬件的数量 |
| 来源 | 哪个比赛 / 活动、何时带回 |
| 状态 | 完好可用 / 待维修 / 已用尽 |
| 照片 | 指向 `图片/` 下的实拍图 |
| 用途建议 | 可复用于哪些场景 |
| 存放位置 | 放在家里 / 工位哪里 |
| 备注 | 其他补充（购买价、连接方式等） |
