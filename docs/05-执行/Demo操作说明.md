# 食刻 · Demo 操作说明

> 目标：现场工作人员和来访嘉宾**打开链接即可理解并演示**核心功能。
> 版本：v2.0 ｜ 更新：2026-08-23
>
> 口径说明：两条演示线——**① SW 链路（H5 真实扫描）**；**② HW-v1 双模组样机（外置平板门外交互 + 内模组条码/视觉识别 + 语音播报 + 关门结算）**，见 §3。HW-v0 单板扫描台（3 秒倒计时拍照）为历史概念 demo，不再作为主演示。

## 2. 环境依赖（重要）

- 手机 / 电脑浏览器（Chrome / Safari 均可）；
- **扫描功能需要摄像头权限 + 联网**（识别走云端 https://shike.live/api/scan，火山方舟视觉模型）；
- 首页 / 库存 / 菜谱 / 我的等页面接口已接通，接口失败时回退演示数据（扫描页为真实识别）；
- **HW-v1 硬件演示**：外置平板（T5-E1 门外交互屏）+ 内模组（XIAO ESP32S3 Sense，条码优先 + 视觉兜底 + 语音播报），数据与 H5 同一后端。

## 3. 操作步骤（3 分钟内）

### 3.1 SW 链路（纯线上，随时可演示）

1. 手机打开 **H5 链接**，电脑打开**大屏链接**；
2. **首页**：看冰箱总览（在库种数 / 临期种数）、保鲜提醒、今日推荐、购物清单预览、家庭共享；
3. 点底部「**扫描**」→ 允许摄像头 → 把食材对准取景框 → 自动识别 → 显示**品名 / 建议保鲜天数 / 置信度 / 建议容器** → 点「确认录入」；
4. 切到「**库存**」：看到刚录入的食材（按容器、剩余天数排序）；「**菜谱**」：看能做的菜与还缺的食材；「**我的**」：成员、购物清单、通知中心；
5. 大屏版：演示库存排行、临期提醒、周度菜谱、月度统计面板；
6. 收尾：**“食刻在场，不浪费每一份食材。”**

### 3.2 HW-v1 硬件链路（有样机时，主打"免手持"）

1. 外置平板待机 → 点【**放入**】（或【取出】），屏幕提示"已通知内模组，请将食材对准镜头"；
2. 拿食品在门口把条码对准内模组镜头（无码走视觉兜底）→ 内模组**本地条码解码（ms 级）+ 云端查库** → 发出 **"叮 + 品名"** 语音播报；
3. 连续扫多件免逐件确认（像超市收银台）；外置平板同步显示最近识别结果；
4. **关门结算**：无差异 → 静默入账；有可疑项 → 平板亮起汇总（放入 X / 取出 Y / 未识别 Z），**一键确认或逐条修正**；
5. 断网时内模组本地记录、恢复联网自动补传，不影响讲解。

> 演示话术：**"买完菜往冰箱里放，门口扫一下就自动记账，关门一次确认。"**

## 4. 演示保底

- 断网 / 摄像头不可用时，页面自动回退演示数据，不影响讲解；
- 识别失败（无码 / 条码被遮）会走视觉品类兜底或提示"转一下条码"，属正常兜底流程。
