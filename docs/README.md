# 食刻 ShiKe · 文档库索引

> 组织方式：传统软硬件工程结构——`docs/` 按域放文档，`firmware/` 放固件，`hardware/` 放硬件工程文件，`frontend/` 放演示页与设备界面参考，`media/` 放宣传素材，`项目资料/` 放赛事活动材料（仅本地）。

## 文档域

```text
docs/
├── 01-产品/     产品总览、需求（用户故事）
├── 02-硬件/     设计基线、成品规格、选型与器件健康度、BOM、样机构建、烧录、测试、实验、图片
├── 03-软件/     后端对接说明、软件端差距分析、外置平板 v1 改造方案（设备界面参考见 [frontend/tablet-ui](../frontend/tablet-ui/README.md)）
├── 04-商业/     商业化分析、出海战略
├── 05-执行/     冲刺安排、风险清单、Demo 操作说明
└── archive/     版本档案：被取代的旧文档按版本归档，不删除
```

## 命名约定

- 当前有效文档使用业务名（如 `设计基线-硬件逻辑梳理.md`）；
- 被取代的文档移入 `archive/`，文件名加版本前缀（如 `硬件形态-v1-磁吸门版...`），并在 `archive/README.md` 登记取代关系；
- 图片统一放所属域的 `images/` 或 `hardware/bom-images/`、`media/`，不在文档旁散放。
