# 食刻 ShiKe · 产品总览

> Slogan：**食刻在场，不浪费每一份食材**
> 一句话：食刻是一台贴在冰箱上的 AI 食品扫描台——把食品拿到镜头前扫一下，云端 AI 认出它是什么、能放多久，库存自动记账；屏幕、手机端和大屏随时告诉你谁快过期、能做什么菜。

## 核心链路

**扫（拍照）→ 认（云端视觉 AI）→ 记（库存 ±1）→ 显（屏幕 + H5 + 大屏）**

## 已实现能力

| 模块 | 能力 |
|---|---|
| 硬件扫描台 | 放入 / 取出 → 倒计时拍照 → 上传识别 → 结果上屏 |
| 云端 AI 识别 | 品名 + 保质期 OCR，低置信不入库 |
| 家庭库存 | 按容器（冰箱 / 零食柜 / 药盒 / 调料柜 / 主食柜）统计，补给 / 消耗双模式 |
| 营养分析 | 饮食均衡评估与改善建议 |
| 购物清单 | 按库存与临期自动生成补货清单 |
| 家庭共享 | 多成员实时同步、分工录入、通知提醒 |
| 浪费统计 | 月度过期 / 浪费汇总 |
| 过期处理建议 | 临期食材自动给出烹饪或处理建议 |
| 手机 H5 / 大屏 | 首页 / 扫描 / 库存 / 菜谱 / 我的；库存排行 / 临期提醒 / 周度菜谱 / 月度统计 |

## 典型使用场景

1. **批量采购入库**：买菜回来，把扫描版贴在冰箱门内侧，食物经过镜头自动识别记账，关门汇总一次确认；
2. **单品放入 / 取出**：拿起食物对着镜头扫一下，立即上传识别，库存 ±1；
3. **日常待机**：常显时钟 + 临期 / 过期提醒 + 今日菜谱，是冰箱门上的“第二块屏”。

## 系统架构

```text
硬件（T5-E1 外置平板 + XIAO 内模组）
  │  HTTPS multipart POST /api/scan（图片 + deviceId + action）
  ▼
云端（shike.live）— 视觉 AI（火山方舟）→ SQLite（库存 / 流水 / 成员 / 菜谱）
  ▼
消费端：设备屏幕 / H5 手机端 / 大屏 Web
```
