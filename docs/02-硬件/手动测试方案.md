> 配合：[BOM 采购清单](./BOM-采购清单.md) 与 [拼接指南](./V1样机-构建方案.md)

| 项 | 准备 |
|---|---|
| 硬件 | 内模组（XIAO Sense + 外设）、外置平板（**T5-E1 复用，零采购**，见 [V1样机-构建方案](./V1样机-构建方案.md) v3.1）、USB 电源 ×2 |

## 2. 测试用例

### T1 硬件上电自检

- 目的：确认两块板供电、启动、串口正常。
- 步骤：分别插 USB 上电，打开串口监视器（115200）。
- 预期：串口输出启动日志；外置平板屏幕点亮。

### T2 摄像头出图

- 目的：确认内模组摄像头工作。
- 步骤：烧拍照示例，对准物体拍照，读串口 / 保存图片。
- 预期：640×480 画面清晰，无花屏 / 黑屏。

### T3 条码解码

- 目的：验证主动扫码主路径（本地解码）。
- 步骤：对 10 个不同 EAN-13 条码各扫 1 次（含曲面 / 反光 / 小字体），记录成功次数。
- 预期：成功率 ≥90%（样机阶段参考值；成品标准 ≥97%）。

> ✅ 本地条码解码（ZXing）已实现：内模组-04 示例编译通过（esp32 2.0.14 + C++17），为当前**主路径**；云端视觉识别保留为无码/解码失败时的兜底（ADR-010）。测试记录注明所用路径（本地条码 / 云端视觉）。

### T4 语音播报

- 目的：验证"叮 + 名称"播报。
- 步骤：播放预置"叮"音；再模拟一次识别后播报名称。
- 预期：喇叭出声清晰，无杂音；断网时播本地缓存 / 品类名。

### T5 Wi-Fi + 上云识别

- 目的：验证拍照上传 shike.live 并返回结果。
- 步骤：连 2.4G Wi-Fi，拍照 → POST /api/scan。
- 预期：返回品名 / 保质期 / 置信度；超时或失败有明确提示。

### T6 完整链路（一按一响一结果）

- 目的：验证"按键 → 拍照 → 识别 → 播报"闭环。
- 步骤：按扫码键，对真实食材执行 5 次。
- 预期：每次一按一响一结果；连续失败 ≤1 次。

### T7 经过事件检测

- 目的：验证放入 / 取出候选。
- 步骤：门开状态，分别把食材放入 / 取出，看串口事件日志。
- 预期：放入出"放入候选"，取出出"取出候选"；空手经过不触发（5 次空手误触发 ≤1 次）。

### T8 中途取出判定

- 目的：验证同一窗口取出又放回识别为"中途取出"。
- 步骤：取出一件 → 放回同一件（身份一致）；再测"取出旧 → 放入新（不同条码）"。
- 预期：前者判定"中途取出"（库存净 0 + 播报提醒）；后者分别记账。

### T9 双模组同步

- 目的：验证内模组扫码 → 云端 → 外置平板显示。
- 步骤：内模组扫码识别 → 打开平板查看库存。
- 预期：平板出现新条目（延迟确认可接受，明确标注同步状态）。

### T10 汇总三通道

- 目的：验证关门结算 → 待确认 → 推送。
- 步骤：构造一次结算（放入 2 / 取出 1），检查三处呈现。
- 预期：平板亮起或待确认可见；App 入口可见；严重差异有推送（未识别 ≥3 件才推送）。

### T11 断网离线队列

- 目的：验证本地队列 + 恢复补传。
- 步骤：断网扫码 5 次 → 恢复网络 → 观察自动上传。
- 预期：恢复后 5 条全部上传，0 丢失、0 重复。

### T12 低光补光

- 目的：验证昏暗环境可识别。
- 步骤：关灯（<50 lux）扫码。
- 预期：补光自动亮，识别成功或明确提示。

### T13 静音模式（可选）

- 步骤：开启静音后扫码。
- 预期：无语音，屏幕显示结果 + 短提示音 / 振动。

### T14 续航（可选 · 需电池）

- 步骤：满电开始计时，按日常节奏使用。
- 预期：内模组 ≥3 周 / 外置平板 ≥3 个月（样机阶段记录实际值即可）。

## 5. 失败处理

1. 单个用例失败 → 先查拼接指南排障表（接线 / 引脚 / 供电）；
2. 仍失败 → 记录现象 + 串口日志原文，按模块排查（摄像头 / 网络 / 音频）；
3. 硬件逻辑问题（非接线 / 配置问题）→ 回填[设计基线](./设计基线-硬件逻辑梳理.md) Issue 表，标记待设计。
