# 食刻 · 硬件 User Stories（含 Extreme Cases）

> 版本：v1.0 ｜ 日期：2026-08-19
> 适用形态：
> - **[已实现]** T5-E1 固定扫描台（USB 供电 · 触屏 · 3 秒倒计时拍照）
> - **[磁吸版]** 磁吸门版（ESP32-S3 · 锂电 · 门内连续扫描 · 设计目标）
> - **[通用]** 两个形态都适用
>
> 版本关系：**[已实现]** = HW-v0（T5-E1 概念 demo），**[磁吸版]** = HW-v1（完整落地目标，开发中；最新形态为双模组分体，见 §8）；对外展示以磁吸版理想场景为准，硬件与软件独立迭代（见[设计基线](./设计基线-硬件逻辑梳理.md) §1.3）。
>
> 优先级：P0 = 主链路必须；P1 = 重要体验；P2 = 可后置
> 格式：用户故事（作为…我想要…以便…）+ 验收标准（Given / When / Then）

---

## 1. 角色定义

| 角色 | 描述 |
|---|---|
| 家庭成员 | 主要使用者（成年人，多数场景独自操作） |
| 老人 | 视力、操作能力受限；手部可能不稳 |
| 儿童 | 身高不足、可能乱按、手湿 |
| 系统 | 固件 + 云端 + 数据库构成的整体 |
| 维护者 | 开发 / 客服 / 售后诊断设备 |

## 2. 核心正向流程（Happy Path）

### US-01 放入一件食品（P0 · 已实现）

> **作为** 家庭成员，**我想要** 把食品拿到镜头前扫一下就能自动识别入库，**以便** 不用手动记录，库存自动更新。

- Given 设备处于待机页（显示【放入】【取出】）
- When 我点击【放入】，经过 3 秒倒计时，把食品对准镜头
- Then 设备拍照上传云端，屏幕显示品名 / 保质期 / 建议容器
- And 我确认后库存 +1，回到待机页

### US-02 取出一件食品（P0 · 已实现）

> **作为** 家庭成员，**我想要** 取出食品时扫一下自动出库，**以便** 库存与实际一致，不会出现"已经吃完还记着"。

- Given 设备处于待机页
- When 我点击【取出】，扫描一件食品并确认
- Then 库存 -1，本次取出记录生效

### US-03 门外单品扫描（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 设备贴在冰箱上时也能对单件食品扫描，**以便** 日常临时拿取不用取下设备。

- Given 设备贴在冰箱外门，处于展示板状态
- When 我按一下【扫描】键，把食品对准镜头
- Then 设备自动抓帧识别，屏幕显示品名 / 保质期，确认后库存 ±1

### US-04 门内连续扫描（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 买菜回家往冰箱放的时候，经过镜头就自动记账，**以便** 一次放入十几件不用逐件操作。

- Given 设备贴在内门，检测到开门
- When 我逐件把食品放进冰箱，每件经过镜头
- Then 每件食品自动抓帧入队，屏幕即时显示"已录入：牛奶 ×1"
- And 过程中不需要我逐件确认

### US-05 批量汇总确认（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 关门前看到本次放入/取出的汇总并一次确认，**以便** 不会因为漏看屏幕而丢记录。

- Given 一次批量扫描结束（我准备关门）
- When 我查看汇总页（本次 N 件：放入 X / 取出 Y / 跳过 Z）
- Then 我可以逐条确认或修正，确认后提交云端
- And 如果我直接关门，汇总自动保存并延迟到下次联网时提交

### US-06 待机展示板（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 不扫描时设备显示时钟、临期提醒和今日菜谱，**以便** 设备不只是扫描工具，平时也有价值。

- Given 设备贴在外门处于待机状态
- When 我经过或按任意键
- Then 屏幕显示时钟 / 临期提醒 / 今日菜谱（或唤醒后再显示）

### US-07 断网兜底显示本地库存（P0 · 通用）

> **作为** 家庭成员，**我想要** 家里断网时设备仍能显示最近的库存和临期提醒，**以便** 断网不影响我了解冰箱状态。

- Given 设备检测到无法连接云端
- When 我尝试查看库存或扫描
- Then 屏幕显示本地缓存的最近库存与提醒，并提示"网络不好"

## 3. 识别与准确性边界（Recognition Edge Cases）

### US-10 识别失败可重拍（P0 · 通用）

> **作为** 家庭成员，**我想要** 识别失败时能重拍而不是卡死，**以便** 一次没对准也能继续完成。

- Given 云端返回低置信或失败
- When 我确认"没看清，请再扫一次"
- Then 回到取景状态可重拍，本次不写入库存

### US-11 低置信度不自动入库（P0 · 通用）

> **作为** 系统，**我想要** 置信度低于阈值的识别结果不直接入库，**以便** 避免错误数据污染库存。

- Given 识别置信度 < 0.5
- When 结果返回
- Then 设备提示"没看清"并进入人工确认 / 重拍流程，不写库存

### US-12 相似物品可区分（P1 · 通用 · 修正）

> **作为** 家庭成员，**我想要** 相似包装的食品（如伊利 vs 蒙牛牛奶）能被区分，**以便** 库存记录准确。

- Given 两件外观相似的食品先后放入
- When 有条码 → 条码查库
- Then 品名精确到具体品牌型号，不互相覆盖
- And 无码（如散装）→ 视觉只承诺品类级（"牛奶"），不承诺品牌区分，必要时汇总页人工修正

### US-13 多件同品批量放入（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 一次放入一排酸奶或一箱鸡蛋时能被正确计数，**以便** 不需要一件一件数。

- Given 多件相同食品连续经过镜头
- When 自动扫描完成
- Then 汇总显示正确数量（如"酸奶 ×6"），允许我手动修正数量

### US-14 堆叠与遮挡（P1 · 通用）

> **作为** 家庭成员，**我想要** 食品被袋子、标签或手部分遮挡时也能尽量识别，**以便** 不必拆开包装才能扫。

- Given 食品部分被遮挡
- When 扫描
- Then 系统给出最佳猜测或明确提示"请移开遮挡物"，而不是报错退出

### US-15 透明包装与液体（P1 · 通用）

> **作为** 家庭成员，**我想要** 透明瓶装水、玻璃罐等反光/透明物品也能被识别，**以便** 大多数日常食品都能扫。

- Given 透明或反光包装的食品
- When 扫描
- Then 识别结果合理，或提示换角度重拍（可接受，但要提示明确）

### US-16 日期/标签被遮挡（P1 · 通用）

> **作为** 家庭成员，**我想要** 保质期文字被手或标签遮挡时能识别出品类并提示"日期待确认"，**以便** 不因为看不清日期而完全无法录入。

- Given 品名可见但日期被遮挡
- When 扫描
- Then 入库时日期标记为"待确认"，不凭空猜测过期日

### US-17 快速掠过镜头（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 动作较快时（1 秒内经过）也能抓拍到，**以便** 正常放东西的节奏不会被识别打断。

- Given 食品快速经过镜头（0.5–1s）
- When 连续取景模式运行
- Then 仍抓到清晰帧并识别，不因模糊而漏检

### US-18 手/手臂误触发（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 只是伸手拿东西、没有放食品时不会被误记入库存，**以便** 库存不会被手部动作污染。

- Given 手或手臂经过镜头但未携带食品
- When 连续扫描
- Then 不产生库存记录（或进入"跳过"候选）

### US-19 冰箱内已有物品入镜（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 开门时冰箱里已有的食品出现在背景里不会重复入库，**以便** 不会每次开门都误加库存。

- Given 开门瞬间镜头内可见冰箱原有食品
- When 进入连续扫描
- Then 只识别"新进入视场的运动物体"，背景物品不触发记账

### US-20 放入/取出方向判定（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 系统能判断食品是放进还是取出，**以便** 库存方向正确，不必每次手动选择。

- Given 一件食品经过镜头
- When 方向判定完成
- Then 正确标记为"放入 +1"或"取出 -1"；无法判定时进入汇总页待我确认

### US-21 重复扫描防重（P1 · 通用）

> **作为** 家庭成员，**我想要** 同一件食品被扫两次时不会记成两件，**以便** 不确定时重扫不会污染数据。

- Given 同一件食品在短时间（如 2 分钟内）被重复扫描
- When 第二次识别结果与第一次相同
- Then 提示"该物品可能已录入"，由我确认是否真的再记一次

## 4. 环境极端条件（Environmental Extremes）

### US-30 低温连续工作（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 设备贴在冰箱门内（2–8°C）能正常连续工作，**以便** 门内形态是可信的。

- Given 设备处于 2–8°C 环境 24 小时
- When 我开门扫描
- Then 摄像头 / 屏幕 / 触摸 / 按键全部正常，识别精度无明显下降

### US-31 冷冻室边界（P2 · 磁吸版）

> **作为** 家庭成员，**我想要** 设备不慎被放进冷冻室（<0°C）时不损坏、不冒风险，**以便** 误放也有兜底。

- Given 设备低于 0°C
- When 被开机使用或充电
- Then 固件检测低温并禁止充电 / 提示移出，设备不损坏

### US-32 凝露与镜头起雾（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 从门内拿出或门外低温时镜头不起雾，**以便** 扫描不会因为起雾而失效。

- Given 设备经历冷热交替（冰箱内 → 室温）或高湿环境
- When 我立即扫描
- Then 镜头仍清晰可用；若有轻微起雾，预热后可恢复且提示等待

### US-33 湿手操作（P1 · 通用）

> **作为** 家庭成员，**我想要** 手湿 / 有油时也能操作设备，**以便** 厨房场景不别扭。

- Given 手指带水或油
- When 我按实体按键（磁吸版）或触摸屏（T5-E1）
- Then 操作有效且不误触、不进水

### US-34 昏暗光线（P1 · 通用）

> **作为** 家庭成员，**我想要** 冰箱内光线不足时也能拍清楚，**以便** 晚上或门内背光也能识别。

- Given 环境光 < 50 lux
- When 进入扫描
- Then 补光灯自动点亮，抓帧仍清晰可识别

### US-35 强光 / 逆光 / 反光（P1 · 通用）

> **作为** 家庭成员，**我想要** 厨房灯光直射或窗外逆光时也能识别，**以便** 摆放位置不受光线限制。

- Given 强逆光或镜面反光
- When 扫描
- Then 自动曝光调整，结果可识别；不可识别时提示调整角度

### US-36 冰箱门信号屏蔽（P0 · 磁吸版）

> **作为** 系统，**我想要** 关门后网络不可用时把数据先落本地，**以便** 门内形态在信号被屏蔽时依然可靠。

- Given 关门后 Wi-Fi 完全不可达
- When 我完成了扫描（在开门窗口内）
- Then 结果先存本地，不阻塞操作
- And 后续网络可用时自动补传，不丢数据

### US-37 关门振动 / 磁吸脱落（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 用力关门时设备不掉落、不误触发，**以便** 日常使用无心理负担。

- Given 正常力度甚至稍用力关门
- When 门关闭产生振动
- Then 设备不脱落；振动不产生虚假扫描或误触

### US-38 门快速开关 / 反复开关（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 开门只拿一件东西就马上关门时也能正确工作，**以便** 短开门（<5 秒）不漏记。

- Given 开门 3–5 秒后立即关门
- When 期间有食品经过
- Then 已入队的帧不丢，识别结果在关门后仍能补全

## 5. 电源与续航（Power Extremes）

### US-40 低电量告警（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 电量低时被明确提醒，**以便** 不会在需要时才发现没电。

- Given 电量 < 20%
- When 设备待机或使用中
- Then 屏幕 / H5 显示低电量提示，建议充电

### US-41 摘下充电（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 摘下设备充电后数据不丢、回来即用，**以便** 充电不影响使用连续性。

- Given 设备低电量，我摘下充电
- When 充至 100% 后贴回
- Then 设备重启后自动恢复待机状态，本地与云端数据一致

### US-42 电量耗尽数据不丢（P0 · 磁吸版）

> **作为** 家庭成员，**我想要** 设备彻底没电后重新充电，本地记录还在，**以便** 不会丢失扫描历史。

- Given 电池耗尽自动关机
- When 重新充电开机
- Then 本地未上传记录保留，联网后自动补传

### US-43 外置平板续航达标（P0 · 外置平板）

> **作为** 家庭成员，**我想要** 日常待机（含展示板模式）能撑 3–4 个月，**以便** 几乎不用想充电的事。

- Given 正常使用节奏（每天 15–20 次走近亮屏 + 按需同步）
- When 一次满电开始计时
- Then 3–4 个月内电量不耗尽（2000mAh，实测数据作为验收依据）

### US-44 断电恢复（P0 · 已实现）

> **作为** 家庭成员，**我想要** USB 供电的设备断电再通电后自动恢复，**以便** 不需要重新操作。

- Given T5-E1 被拔掉电源再插回
- When 上电
- Then 自动回到待机页，不进入异常状态

## 6. 网络与同步（Network Extremes）

### US-50 断网离线扫描（P0 · 通用）

> **作为** 家庭成员，**我想要** 完全断网时也能完成扫描动作，**以便** 断网不阻断日常使用。

- Given 无任何网络
- When 我扫描一件食品
- Then 板端分类 + 本地目录给出结果（标注"待联网确认"），队列缓存，联网后补传

### US-51 开门窗口补传（P1 · 磁吸版）

> **作为** 系统，**我想要** 每次开门联网时优先补传积压数据，**以便** 关门期间的数据尽快生效。

- Given 本地存在未上传记录
- When 设备联网（开门或贴外门）
- Then 按时间顺序自动补传，成功即从本地队列清除

### US-52 弱信号 / 高延迟（P1 · 通用）

> **作为** 家庭成员，**我想要** Wi-Fi 信号弱时扫描不会无限等待，**以便** 体验可控。

- Given 信号弱或延迟 > 3s
- When 扫描上传
- Then 超时（如 15s）后明确提示"网络不好，请重试"，本次动作可重试不丢失

### US-53 云端超时 / 服务器不可用（P0 · 通用）

> **作为** 家庭成员，**我想要** 服务器故障时设备不崩溃，**以便** 服务恢复后一切正常。

- Given 云端 5xx 或不可达
- When 扫描
- Then 设备提示"服务暂时不可用"，可稍后重试；已扫图片不丢

### US-54 多端数据一致性（P1 · 通用）

> **作为** 家庭成员，**我想要** 设备屏幕、H5、大屏看到的库存一致，**以便** 不会出现"设备说已录入，手机看不到"。

- Given 我在设备上完成一次扫描确认
- When 我打开 H5 或大屏
- Then 数据实时一致（或明确标注同步状态）

## 7. 生命周期与维护（Lifecycle & Maintenance）

### US-60 首次开机配网（P1 · 通用）

> **作为** 家庭成员，**我想要** 第一次使用能快速连上家里 Wi-Fi，**以便** 不需要专业技术人员。

- Given 设备首次上电
- When 我按引导操作（屏幕提示 / 扫码配网）
- Then 3 分钟内完成配网并进入待机页；失败有明确重试路径

### US-61 位置切换（内门 ↔ 外门）（P1 · 磁吸版）

> **作为** 家庭成员，**我想要** 设备从内门换到外门时自动或手动切换模式，**以便** 不用每次重新设置。

- Given 设备被取下并贴到另一面
- When 完成放置
- Then 自动识别位置（或提示我选择），进入对应模式（内门=连续扫描 / 外门=展示板）

### US-62 OTA 升级（P1 · 通用）

> **作为** 系统，**我想要** 固件可远程升级且失败可回滚，**以便** 修复问题和发布新功能不用拆机。

- Given 新固件版本可用
- When 设备联网且空闲
- Then 自动或提示下载升级；升级失败自动回退旧版本，不影响使用

### US-63 存储写满（P1 · 通用）

> **作为** 系统，**我想要** 本地存储满时自动清理已上传的旧数据，**以便** 不会因为存满而无法工作。

- Given 本地缓存接近写满
- When 新记录需要写入
- Then 优先清理已成功上传的记录；无法清理时提示维护

### US-64 时钟漂移（P1 · 通用）

> **作为** 家庭成员，**我想要** 设备离线很久后时间仍然基本准确，**以便** 保质期计算和记录时间可靠。

- Given 设备离线超过 3 天
- When 重新联网
- Then 自动校时；离线期间使用本地 RTC 计时并标注"可能偏差"

### US-65 清洁镜头（P2 · 通用）

> **作为** 家庭成员，**我想要** 镜头脏了能自己清洁，**以便** 长期使用识别不下降。

- Given 镜头有污渍
- When 我按说明擦拭
- Then 清洁不损坏镜头 / 密封结构，之后识别恢复

### US-66 设备故障可诊断（P1 · 通用）

> **作为** 维护者，**我想要** 设备异常时有可读取的诊断信息，**以便** 远程定位是硬件还是固件问题。

- Given 设备异常（无法开机 / 反复重启 / 不识别）
- When 维护者查看心跳日志或串口
- Then 能看到最近事件、温度、错误码，辅助判断原因

### US-67 锂电低温充电安全（P0 · 磁吸版）

> **作为** 系统，**我想要** 低温下禁止或限制充电，**以便** 避免锂电在冰箱内充电的安全风险。

- Given 电池温度低于安全阈值（如 0°C）
- When 插入充电
- Then 不充电并提示"温度过低，请移出冰箱后充电"

### US-68 家庭隐私（P1 · 通用）

> **作为** 家庭成员，**我想要** 扫描的照片和库存数据只属于我的家庭，**以便** 隐私可控。

- Given 家庭成员查看数据
- When 访问库存 / 扫描记录
- Then 仅本家庭可见；照片默认不公开，可设置自动清理

### US-69 设备更换 / 数据迁移（P2 · 通用）

> **作为** 家庭成员，**我想要** 设备损坏换新后库存数据还在，**以便** 硬件生命周期不影响数据资产。

- Given 新设备绑定同一家庭
- When 完成配网
- Then 云端库存 / 提醒完整同步到新设备

## 8. HW-v1 双模组分体形态（新增基线 · 2026-08-19）

> 形态说明：外置磁吸平板（门外 · 触屏交互 / 库存展示 / 告警弹窗）+ 内部摄像头模组（门内 · **单摄像头**，门内侧上部朝冰箱内部，识别 / 语音播报 / 经过事件检测），出厂可磁吸组合。识别 = EAN-13 条码 OCR + YOLO 视觉，双-check 双重校验。

### US-70 主动录入完整链路（模式A · P0）

> **作为** 家庭成员，**我想要** 在外置平板点【放入】后，把食材对着门内摄像头扫一下就能语音确认录入，**以便** 双手都在拿食材时无需操作平板。

- Given 我在外置平板点击【放入】
- When 内模组收到指令进入待命，我拿食材对着摄像头
- Then 内模组识别（条码优先 / 视觉兜底）并语音播报「叮｜物品名称」
- And 连续多件均可依次录入，无需逐件确认

### US-71 关门结算 + 差异可见（模式A · P0 · 修正）

> **作为** 家庭成员，**我想要** 关门后系统结算本次放入 / 取出，差异清楚可见，**以便** 不漏记不误记，又不用专门操作。

- Given 我完成放入 / 取出并关门
- When 系统结算事件序列，交叉验证语音清单与事件识别结果
- Then 无差异 → 静默入账，仅留记录；有可疑项 → 汇总进入"待确认"
- And 下次我查看外置平板或 App 时可见，可一键确认或逐条修正

### US-72 条码优先识别（EAN-13 · P0 · 主动扫码主路径）

> **作为** 家庭成员，**我想要** 有完整包装的食材扫条码就能精确识别，**以便** 品名 / 保质期准确，无需靠视觉猜测。

- Given 食材有 EAN-13 条码
- When 我把条码对准镜头（或放入时顺手在门口停一下）
- Then 解码成功 → 语音播报精确品名与保质期（查库），"叮"即时反馈
- And 检测到条码但解码失败 → 语音引导"请转一下条码"（<2s），不打断连续扫节奏
- And 未检测到条码（无码 / 被手遮）→ 直接视觉识别播品类名，不进入"请转条码"流程
- And 我偶尔直接放入不扫 → 视觉品类级兜底 + 汇总标注"非条码识别"，不阻塞但可见

### US-73 无码 / 去包装食材视觉识别（P1）

> **作为** 家庭成员，**我想要** 没有条码的食材（散装菜、切开肉）也能识别，**以便** 覆盖非包装场景。

- Given 食材无条码或已去包装
- When 内模组 YOLO 识别
- Then 给出品类级结果（如"猪肉块"），标注"无条码，保质期按品类默认值"，可人工修正
- And 置信度 ≥85% → 直接播品类名入账，不逐件确认；<85% → 播"没看清"，连续失败进汇总页待确认

### US-74 被动识别（模式B · P1 · 修正：经过事件检测）

> **作为** 家庭成员，**我想要** 完全不操作也能自动记账，**以便** 忘记主动录入时也有记录。

- Given 我开门放入 / 取出食材
- When 食材从门口进入视野（放入）或从层前部离开视野（取出）
- Then 内模组在物体未被遮挡时抓拍识别，记录"放入 / 取出候选"
- And 识别不确定的候选进入待确认列表（外置平板弹窗）

### US-75 漏识别事件补确认（P1 · 修正：无区域补拍）

> **作为** 家庭成员，**我想要** 被外层食材挡住的内层食材，在外层取走后能自动补拍，**以便** 内层食材状态保持更新。

- Given 某件食材经过时条码 / 视觉未识别成功
- When 关门汇总时发现未识别候选
- Then 外置平板列出"未识别 N 件"，我补选品类或忽略
- And 不承诺对放入后部 / 被上层遮挡的食材事后补拍

### US-76 识别失败人工兜底（P0）

> **作为** 家庭成员，**我想要** 多次识别失败时在外置平板上手动确认，**以便** 识别不准不写进库存。

- Given 同一食材多次识别置信度不足（含首放即遮挡场景）
- When 内模组上报低置信
- Then 外置平板 / APP 弹窗，提示我手动确认或调整位置重拍

### US-77 冰箱分层模型配置（P2 · 降级为增强项）

> **作为** 家庭成员，**我想要** 在软件里配置自家冰箱的隔层数量和边界，**以便** 图像按层切割识别，定位更准。

- Given 我打开分层配置页（可选）
- When 我设置隔层数量与每层边界（可拍照框选，或直接用默认单容器）
- Then 事件记录参考画面高度映射层位，不承诺精确到层
- And 不配置也可正常使用（库存按容器 / 品类粒度）

### US-78 内外模组配对与出厂组合（P1）

> **作为** 家庭成员，**我想要** 开箱时内外模组已经配对好，**以便** 不需要自己配网配对。

- Given 出厂两模组磁吸组合
- When 我首次上电
- Then 自动完成配对与绑定家庭；分离后放回组合位可充电 / 同步

### US-79 内外模组断连降级（P0）

> **作为** 家庭成员，**我想要** 内外模组之间或网络断开时，扫描记录不丢，**以便** 断连不影响数据完整性。

- Given 内外模组通信中断（关门 / 网络波动）
- When 内模组完成识别
- Then 结果先存内模组本地队列，恢复连接后自动同步（0 丢失、不重复）

### US-80 分割肉类场景（P1）

> **作为** 家庭成员，**我想要** 一块肉切开分装后，系统不会把它当成全新食材，**以便** 库存不过度膨胀。

- Given 同一块肉被切开分装多次放入
- When 条码 / 视觉识别
- Then 完整包装走条码精确记账；去包装后按"品类 + 近似份量"粗粒度记账，允许合并 / 修正

### US-81 确认延迟可接受（P0）

> **作为** 家庭成员，**我想要** 关门后双-check 结果不一定立刻弹出，**以便** 断网时也不阻塞我的动作，稍后查看时仍能纠错。

- Given 我完成放入并关门（内模组可能断网）
- When 全景 / 比对在联网后完成
- Then 差异结果缓存在外置平板，我下次查看平板或 APP 时可见并可一键修正
- And 不因确认未完成而阻塞下次扫描

### US-82 取出闭环（P0 · 完善）

> **作为** 家庭成员，**我想要** 取出食材后系统自动识别并出库，关门时一次确认，**以便** 不用每次手动点【取出】，库存也能及时减少。

- Given 我开门取走一件食材
- When 食材离开视野，内模组抓拍识别"取出物"
- Then 识别高置信 → 关门汇总直接列出"取出：牛奶 ×1"，我扫一眼确认即出库
- And 识别低置信 / 未识别 → 汇总页弹窗"取出了什么？"，我补选或忽略
- And 汇总支持标记用途（吃了 / 扔了 / 移到别处），计入消耗与浪费统计

### US-83 断网语音降级（P1）

> **作为** 家庭成员，**我想要** 断网时扫码也有语音反馈，**以便** 知道识别成功与否。

- Given 内模组离线
- When 我扫码识别
- Then 播报"叮" + 本地目录品类名（如"叮｜牛奶"），精确品名 / 保质期联网后补全

### US-84 隐私录制控制（P1）

> **作为** 家庭成员，**我想要** 知道摄像头何时在录、并能物理关停，**以便** 隐私可控。

- Given 内模组事件驱动录制（开门 / 关门 / 补拍）
- When 录制进行
- Then 指示灯亮起；镜头盖（磁吸挡片）关闭后停止录制与识别
- And 影像默认本地 / 私有存储，不对外公开

### US-85 开箱快速设置（P1）

> **作为** 家庭成员，**我想要** 开箱 5 分钟内完成配对和冰箱分层配置，**以便** 不用读说明书。

- Given 首次上电
- When 我按引导拍照冰箱内部
- Then 系统自动识别隔层边界，我微调确认后即可使用（默认全冰箱单层也可用）

### US-86 湿手触屏防误触（外置平板）（P1）

> **作为** 家庭成员，**我想要** 手湿或带油时碰平板不会误操作，**以便** 厨房使用不烦躁。

- Given 手指带水 / 油接触外置平板
- When 我触控操作
- Then 主要操作可完成，误触率 ≤5%；短暂水渍覆盖不触发随机操作

### US-87 内模组电量与充电（磁吸回平板）（P1）

> **作为** 家庭成员，**我想要** 内模组没电时贴回外置平板就能充，**以便** 不用找充电线，也不会在要用时没电。

- Given 内模组电量 <20%（提前预警）
- When 我取下内模组贴回平板组合位
- Then 磁吸对齐 + pogo 触点自动充电，1 小时内充至 80%；充电期间本地队列不丢
- And 平板电量 <50% 时停止反向供电（保护平板续航）；内模组保留 USB-C 直充备用
- And 充电期间扫码暂不可用，App 提示"内模组充电中"

### US-88 中途取出后放入（混合序列）（P0）

> **作为** 家庭成员，**我想要** 一次开门里先取出旧食材再放入新食材时，系统能正确区分两件事，**以便** 一出一进不混淆、不丢账。

- Given 我开门后先取出一件旧食材，再放入一件新食材（可能外观相似）
- When 关门结算事件序列
- Then 系统分别记为"取出 A"和"放入 B"，不互相覆盖
- And 无法区分（如两件相似无条码）时，汇总页逐条列出供我确认

### US-89 中途取出（同一窗口内取出又放回）（P1）

> **作为** 家庭成员，**我想要** 拿东西出来看看、用一部分又放回时，系统识别为"中途取出"并播报提醒，**以便** 库存不被搞乱，我也知道系统注意到了。

- Given 我在同一开门窗口内取出食材后又放回（检查保质期 / 用了一部分 / 挪层）
- When 放回时系统判定"身份一致"（同条码 / 视觉高匹配）
- Then 库存净 0，不分别记账；播报"叮｜牛奶（中途取出）"
- And 身份不一致（如放新取旧）→ 正常记"取出 A / 放入 B"两笔
- And 部分消耗不精确追踪，用户可在 App 手动修正

### US-90 偶尔不扫的软兜底（P1 · 主路径为主动扫码）

> **作为** 家庭成员，**我想要** 不刻意对准条码也能完成基本记账，**以便** 着急 / 懒得配合时不被卡住。

- Given 我拿着食材直接放进冰箱（没扫条码）
- When 关门结算
- Then 系统以视觉品类级结果记账，并在汇总标注"非条码识别（可能不准）"
- And 无强制打断；精确信息可在汇总页补扫或忽略

### US-91 批量连续扫（收银台式）（P0）

> **作为** 家庭成员，**我想要** 买菜回来一次扫多件时像超市收银台一样连续通过，**以便** 批量入库不费时。

- Given 我点了【放入】进入连续扫模式
- When 我逐件拿食材经过镜头
- Then 每件"叮 + 名称"即时播报，无需逐件确认
- And 10 件约 15–20s 完成；重复扫同一件有防重提示

### US-92 库存差异手动修正（P1）

> **作为** 家庭成员，**我想要** 系统在 App 里把可疑差异列出来，我自己改，**以便** 不用为"可能不准"的库存专门做盘点。

- Given 关门汇总发现未识别 / 不一致项（或我在库存页发现错误）
- When 我在 App（H5 / 外置平板）库存页操作
- Then 可直接补加、删除、编辑条目（复用快速录入，需后端 manual 写入接口）
- And 系统标记修正来源为"手动"，不干扰自动记账

### US-93 汇总三通道呈现（P0）

> **作为** 家庭成员，**我想要** 关门后差异要么在我面前亮起、要么在我下次打开时出现、严重时才推送，**以便** 不打扰日常又不漏重要修正。

- Given 我完成一次开门会话并关门
- When 结算完成
- Then 无差异 → 静默；有可疑项 → 外置平板下次唤醒时显示"待确认" + App 首页入口可见
- And 仅差异显著时（如未识别 ≥3 件）才推送提醒
- And 一键确认或逐条修正均可

### US-94 静音模式（P1）

> **作为** 家庭成员，**我想要** 深夜或需要安静时关闭语音播报，**以便** 不吵到家人。

- Given 我开启夜间静音时段（App 设置）或按快速静音键
- When 我扫码
- Then 不播语音，改为屏幕显示 + 短促提示音 / 振动
- And 静音时识别结果仍在屏幕和汇总页可见
