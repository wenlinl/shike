# 食刻 · HW-v1 硬件选型（模块与方案）

> 版本：v1.3 ｜ 创建：2026-08-20 ｜ 更新：2026-08-21（摄像头降级目标 OV2640 → OV3660：OV2640 已停产，样机与定焦降级统一改走 OV3660）
> 依据：[设计基线](./设计基线-硬件逻辑梳理.md) v4.0
> 范围：双模组分体（外置平板 + 内模组）的器件选型与解决方案；成本为小批量估算，供设计评审，非最终采购价。
> 货币：本文金额均为**人民币（¥ CNY）**。

---

## 1. 选型原则（从设计基线映射）

| 基线约束 | 选型要求 |
|---|---|
| 条码主路径 + 本地优先（ADR-010） | 板端条码解码（ms 级）+ 本地 YOLO 品类（目标 ≤500ms，实测后定，可接受 ≤800ms）→ 主控需 PSRAM |
| VCM 自动对焦（ADR-006） | 摄像头需带 AF 马达（5–50cm 可变焦） |
| FOV 垂直 ≥60–70° / 水平 ≥100° | 广角镜头 |
| 语音播报（叮 + 名称） | I2S 功放 + 喇叭；名称走云端 TTS 音频缓存 |
| PIR 接近唤醒 + 3–4 个月续航（ADR-003） | 低功耗 PIR + 深睡 |
| 磁吸回平板充电（pogo 触点） | 组合位触点 + 平板反向供电 |
| 低温禁充（<0°C） | 充电管理带 NTC |
| 内模组独立 Wi-Fi + 开门窗口同步（ADR-008） | ESP32-S3 集成 Wi-Fi（零额外成本） |
| 单摄像头朝冰箱内部偏门口 20–30° | 镜头朝向靠结构件，不靠选型 |

## 2. 外置平板（门外 · 交互 + 展示 + 充电站）

| 模块 | 需求规格 | 推荐方案 | 成本（¥ CNY） | 理由 / 备注 |
|---|---|---|---:|---|
| 主控 | Wi-Fi + LVGL UI + 反向充电控制 | **ESP32-S3-WROOM-1-N16R8**（16MB Flash + 8MB PSRAM） | 18–22 | UI 需 PSRAM；Wi-Fi 集成；库存数据在云端，本地缓存量小 |
| 屏幕 | 彩色触屏，展示库存 / 告警 / 汇总 | **2.4" ST7789 240×320 + CST816S 电容触摸** | 13–18 | 与 T5-E1 同方案复用；湿手防误触靠软件策略（I-27 / EXP-15） |
| 接近唤醒 | 低功耗 PIR，静态 <50µA | **AM312 数字 PIR**（或同规格低功耗 PIR） | 2–5 | 30s 自动熄屏 + 触摸续亮；待机电流 EXP-06 实测 |
| 电池 | 2000mAh，3–4 个月 | **3.7V / 2000mAh 锂聚合物（定制尺寸）** | 15–22 | 目标日均 ≤20mAh（优化 ≤12mAh） |
| 电源管理 | 充电 + 反向供电（给内模组） | **IP5306**（集成充电 / 升压 / 反向充电） | 3–5 | 组合位反向充内模组；平板 <50% 停止反向供电 |
| 磁吸 / 触点 | 贴门外 + 组合位对齐 | **N52 磁铁 ×4 + pogo pin ×4** | 4–6 | 与内模组组合位对齐，触点充电 / 同步 |
| 结构 | 磁吸外壳 | 3D 打印（量产转注塑） | 8–12 | 硅胶垫防滑防震 |

**小计：约 ¥55–90**（主选 2.4" 屏 + 光敏可压到下限）

## 3. 内模组（门内侧 · 感知 + 识别 + 语音）

| 模块 | 需求规格 | 推荐方案 | 成本（¥ CNY） | 理由 / 备注 |
|---|---|---|---:|---|
| 主控 | 摄像头 + 条码解码 + 本地 YOLO + Wi-Fi + 音频 | **ESP32-S3-WROOM-1-N32R8**（32MB Flash + 8MB PSRAM） | 25–30 | 板端 YOLO 需 PSRAM；模型 + 字库 + 缩略图队列需大 Flash；N32R8 比 N16R8 多 16MB（关键） |
| 摄像头 | VCM 自动对焦 + 广角 + 条码清晰 | **OV5640 AF 版（5MP / DVP / 带 VCM 马达）** + 广角镜头（水平 ≥100°） | 25–40 | ADR-006；5–50cm 可变焦；实际跑 VGA 级（640×480）满足条码解码 |
| 补光 | 门内低光 / 昏暗环境 | **白光 LED ×2 + 三极管驱动** | 2 | 事件触发时才亮，降低功耗 |
| 音频 | 语音播报"叮 + 名称" | **MAX98357A（I2S 功放）+ 1W 喇叭** | 5–8 | 名称音频：云端 TTS 首次生成 → 本地缓存 → 断网播缓存 / 品类名；"叮"本地合成 |
| 门开检测 | 低功耗唤醒（事件驱动） | **低功耗加速度计（LIS2DW12 / ADXL345，运动唤醒）** | 3–8 | 检测门旋转唤醒；待机 <100µA；光敏（开门灯亮）为备选 |
| 电池 | 1000mAh，3–4 周 | **3.7V / 1000mAh 锂聚合物** | 8–12 | 事件驱动工作 35–50mAh/天 |
| 充电 | 触点 + USB-C 备用 + 低温禁充 | **TP4056 + 触点输入 + NTC 温度检测** | 2–4 | 5.3 低温禁充（<0°C） |
| 存储 | 模型 + 字库 + 事件队列 | 32MB Flash（N32R8），必要时加 microSD | 含主控 | 缩略图队列几 MB；US-63 清理策略 |
| 磁吸 | 贴门内侧 + 组合位对齐 | **N52 磁铁 ×4 + pogo pin ×4** | 4–6 | 与平板组合位对齐（出厂 / 充电 / 同步） |
| 结构 | 镜头窗防雾 + 密封 | 3D 打印外壳 + 防雾窗片 | 8–12 | 凝露待 EXP-03 定结构方案 |

**小计：约 ¥75–125**（降级 OV3660 定焦 + 光敏可压到下限）

## 5. 关键风险与待验证点

| # | 风险 | 影响 | 缓解 / 验证 |
|---|---|---|---|
| R1 | OV5640 AF 在 ESP32-S3 DVP 的驱动成熟度（5MP 需降采样，AF 马达控制） | 摄像头是识别主链路，驱动不稳则全盘受影响 | 先做摄像头驱动原型验证；若 EXP-12 证明定焦 + 动作引导可读率 ≥90%，可降级 OV3660 定焦省 ¥5–30 |
| R2 | 板端 YOLO 量化在 ESP32-S3 的推理时间与精度 | ADR-010 成立的关键 | EXP-11（1000 张数据集 + ESP-DL 基准，目标 ≤500ms、可接受 ≤800ms；不达标降级"板端轻量分类 + 云端精识别"） |
| R3 | 中文 TTS 板端质量差 | "叮 + 名称"播报体验 | 走云端 TTS 音频缓存；断网播缓存 / 品类名（US-83） |
| R4 | 内模组天线在门内被屏蔽（关门） | 同步延迟 | 架构已按开门窗口同步兜底（ADR-008）；EXP-01 补多台数据 |
| R5 | 加速度计 / PIR 待机电流超标 | 续航目标（3–4 周 / 3–4 月） | EXP-06 实测；选低功耗型号（LIS2DW12 静态 <1µA） |
| R6 | 电容触摸湿手误触 | 外置平板厨房场景 | EXP-15 实测；软件锁 + 唤醒手势 |

## 6. 待拍板的选型决策（效果 × 成本）

| # | 决策 | 效果差异 | 成本差异 | 我的倾向（含成本） |
|---|---|---|---|---|
| D1 | 平板屏幕 | 2.8" 信息密度更高；2.4" 库存列表紧凑但可用 | 2.8" 贵 ¥7–17/台 | **2.4" 主选**（复用 T5-E1 成熟方案，省钱）；UI 原型若放不下再升 2.8" |
| D2 | 摄像头 | AF 容忍用户动作偏差（扫码主路径核心）；定焦要求固定距离，命中率风险 | OV5640 AF 贵 ¥10–25/台 | **OV5640 AF 先定**（扫码是产品价值，不宜为省钱冒险）；设降级路径：EXP-12 证明定焦达标 → 换 OV3660 定焦（OV2640 已停产，不再作为降级目标） |
| D3 | 内模组 Flash | N32R8 免 SD（少失效点、启动快）；N16R8+SD 方案等价 | 两者基本持平（N32R8 甚至更优） | **N32R8 无悬念**——成本不劣、效果更优（✅ 已确认 2026-08-21） |
| D4 | 门开检测 | 光敏靠"开门必亮灯"物理事实，检测可靠、零安装；加速度计额外提供门开角数据 | 加速度计贵 ¥2–5/台 | **光敏主选**（¥1–3，成本最低且可靠）；加速度计列为可选增强（需要门开角数据时再上） |

> 成本逻辑总结：**核心价值处不省**（D2 扫码精度）、**无差异处选优**（D3 Flash）、**可替代处省钱**（D1 屏幕、D4 门开检测）。

### 8.2 V1 样机版说明（当前执行）

**原则**：全部用现成模块 / 开发板拼装，不做定制 PCB、不开模，快速验证核心链路。

**验证目标**：

1. 本地条码解码（ESP32-S3 + ZXing 移植，ms 级）；
2. 本地 YOLO 品类识别（ESP-DL 量化，目标 ≤500ms、可接受 ≤800ms）——ADR-010 成立的关键；
3. 扫码命中率（EXP-12 预跑：朝向分布、对焦距离、可读率）；
4. 语音反馈链路（叮 + 名称播报 / 断网降级）；
5. 经过事件检测 + 中途取出判定（EXP-16 预跑）；
6. 双模组通信（开门窗口同步 / 本地队列）；
7. 关门汇总三通道闭环（设备 + 待确认 + 推送）。

**明确不做（样机阶段）**：定制 PCB、外壳开模、pogo 触点（用线代替）、防水防雾结构、低温 / 凝露验证、续航精确标定。

**成本构成（约 ¥100–165）**：两块 ESP32-S3 开发板或核心板（¥60–100）+ OV3660 模块（¥10–18）+ 屏幕（¥15–18）+ 功放喇叭（¥8）+ 光敏 / 按键（¥3）+ 电池（可选 ¥15–25）+ 简易结构 / 飞线（¥0–10）。

> 手头已有 T5-E1 与 ESP32-S3 核心板可复用，实际现金支出可进一步压低。

## A.3 与 OV2640 同类的「老化风险」器件

摄像头是本次暴露的主风险，但扫描后确认：**器件清单里没有第二个 OV2640 级（全面停产）的器件**，最接近的是几个「老而稳 / 需注意」项：

| 器件 | 老化程度 | 风险 | 对策 |
|---|---|---|---|
| OV5640 | 2011 年前后发布，约 15 年 | 未见官方 EOL，但属老器件，个别模组厂商已下架自家 OV5640 板卡；长期供货依赖渠道 | 量产双货源：OV5640 AF 主选 + **GC2145 AF（Arducam 2MP AF 模组）** 第二货源；与代理商谈长协 |

## A.4 行动建议

**样机采购（立即）**

1. XIAO Sense 下单时向店家确认**摄像头为 OV3660 新批次**（旧批次 OV2640 也能跑样机，但没必要再买旧批次）；
2. 如单独补摄像头模块：买 OV3660 定焦广角（¥10–18）或 OV5640 AF（¥25–40），DVP 24pin；
3. 传感器 / 功放等小模块按 BOM 关键词买，选 3.3V 兼容。

**量产前（S2 工程样机）**

1. **摄像头三线货源**：OV5640 AF（主选）+ GC2145 AF（第二货源，Arducam）+ OV3660 定焦（EXP-12 通过后的降级线）——三条线各打样一版驱动；
2. **N32R8 交期确认**：向立创 / 乐鑫代理商确认 ESP32-S3-WROOM-1-N32R8 现货与 MOQ，不行则回退 N16R8 + SD 方案（成本等价，D3 已有预案）；
3. **IP5306 采购管控**：指定英集芯原厂料号，防 NXP 停产同名件混入；
4. **PIR 转定制**：样机用 AM312 验证功耗预算，量产画进平板 PCB（低功耗模拟 PIR），EXP-06 实测待机电流；
5. **加速度计**：统一 LIS2DW12，不再评估 ADXL345。

**供货策略**

- 核心件（主控 / 摄像头 / PMIC）保持 ≥2 货源，摄像头按「AF 主 + AF 备 + 定焦降级」三线，OV2640 从所有采购清单移除；
- 每季度复核一次 OV5640 / ST7789 / TP4056 等老器件的 EOL 公告（乐鑫、ADI、OmniVision 官网 + 立创生命周期字段）。
