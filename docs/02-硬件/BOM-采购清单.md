## 1. 采购原则

1. **摄像头用现成板**（XIAO Sense 自带）——避免零基础接 14 根 DVP 线；
2. **XIAO 只在官方渠道买**（Seeed 天猫旗舰店 / 立创商城），别买仿品；
3. **外置平板分两档**：省钱档（核心板 + 屏幕自己接 7–8 根线）/ 省心档（BOX-3 全内置零接线）；**有 T5-E1 则零采购**；
4. **电池先可后置**：初期用 USB 供电跑功能，续航验证再上电池；
5. 所有物料淘宝/立创可买到，按"搜索关键词"购买。

## 7. 渠道与加急说明

### 7.1 正品保障（重点）

- **XIAO Sense + Grove Shield**：只在 **Seeed 天猫官方旗舰店（seeedstudio旗舰店）** 或 **立创商城** 买——认准官方资质；**别在拼多多买**（仿品多，引脚/摄像头排线有坑，10 天冲刺经不起）；
- 摄像头模块（如补买 OV3660/OV5640）：淘宝，注意 DVP 排线接口、AF 版是否带 VCM 马达；
- 传感器 / 功放 / 喇叭等小模块：淘宝几块钱，选 **3.3V 兼容** 的（BOM 已注明）。

### 7.2 加急策略（10 天冲刺）

1. **京东自营**（次日达）：开发板类最快；
2. **淘宝同城现货**：下单前问"今天能发吗？同城次日到？"，选顺丰 / 京东物流；
3. **三路下单兜底**：同城 / 京东 / 立创各下一单，哪路先到用哪路；
4. XIAO Sense 与扩展板**同店下单**，一次发货省时间。
