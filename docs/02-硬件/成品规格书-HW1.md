## 1. 成品定义与质量红线

### 1.1 成品 = 双模组分体，全功能

- 外置平板（门外）：触屏交互、库存 / 告警展示、汇总三通道、PIR 唤醒、2000mAh 电池、磁吸 + pogo 触点；
- 内模组（门内侧）：VCM 自动对焦摄像头、条码本地解码、本地 YOLO 品类、语音播报、经过事件检测、光敏门开检测、补光灯、1000mAh 电池、低温禁充；
- 出厂组合：两模组磁吸贴合，触点充电 / 同步 / 配对。

### 1.2 质量红线（不可妥协）

| # | 红线 | 标准 | 依据 |
|---|---|---|---|
| Q1 | 识别准确率 | 条码 ≥97%；本地 YOLO 品类 mAP ≥85% | G9 / EXP-07/11 |
| Q2 | 识别时延 | 本地条码 <100ms；目录命中 <50ms；云端查库 P95 <2s | G3 |
| Q3 | 续航 | 外置平板 ≥3 个月；内模组 ≥3 周 | G2 |
| Q4 | 数据可靠 | 断网 100 次 0 丢失、0 重复 | G6 |
| Q5 | 低温安全 | <0°C 禁充；2–8°C 连续工作正常 | G5/G8 |
| Q6 | 隐私 | 录制指示灯 + 物理镜头盖 + 影像识别后不留存 | 7 |
| Q7 | 结构可靠性 | 100 次关门 0 脱落；pogo 触点 1 万次接触 | G7 |
| Q8 | 环境 | 24h 低温无凝露影响识别 | G5 |

## 4. 成本可控策略（不砍功能怎么压）

| 手段 | 说明 | 潜在节省 |
|---|---|---|
| D2 降级路径 | EXP-12 证明定焦 + 转动引导可读率 ≥90% → OV3660 定焦替代 OV5640 AF | ¥5–30/套 |
| 共用 PCB | 外置平板 / 内模组共用部分电源与接口设计 | ¥5–10/套 |
| 量产规模 | BOM 按 5k–20k 量询价（镜头 / 主控有阶梯价） | 10–20% |
| 结构简化 | 外壳先 3D 打印验证，量产注塑优化材料 | ¥5–10/套 |
| 电池定制 | 平板 2000mAh 换通用尺寸 18650/软包现货 | ¥3–8/套 |
| 屏幕共用 | 与已有 T5-E1 供应商同款 2.4" 屏，量价 | ¥3–5/套 |

**底线**：节省只来自"选型与工程优化"，不来自砍功能或降红线。

## 5. 从样机到成品的路径

| 阶段 | 做什么 | 验证什么 | 门禁（过了才进下一阶段） |
|---|---|---|---|
| S1 逻辑验证 | V1 样机（XIAO Sense 等）跑通：扫码 → 识别 → 播报 → 上云 → 汇总 | 产品逻辑与识别链路 | M1–M5 全过（构建指南 §5） |
| S2 工程样机 | 定制双模组 PCB（ESP32-S3 ×2 + 全功能器件），OV5640 AF 驱动 | 硬件工程可行 | F1.1/F1.3 达标；条码 ≥97% 初测 |
| S3 结构样机 | 外壳 + 磁吸 + pogo 触点 + 防雾窗 + 镜头盖 | 结构与交互 | 100 次关门 0 脱落；pogo 接触可靠 |
| S4 环境与认证样机 | 低温 / 凝露 / 续航 / 功耗 / 充电安全 + PSE/TELEC/FCC 送样 | 环境与合规 | G2/G5/G6/G8 全过；认证通过 |
| S5 试产 | 小批量（100–500 台）组装 + 全检 | 可制造性 | 良率 ≥95%；成本达标 |
| S6 量产 | 批量生产 + 供应链 | 交付 | 财务模型达标 |

> 关键依赖：S2 的 OV5640 AF 驱动（R1）与本地 YOLO（R2）是两条关键路径，需在 S1 阶段同步启动 EXP-11 数据与摄像头驱动原型。
