## 1. 目标硬件

| 部件 | 型号 / 规格 | 角色 |
|---|---|---|
| 外置平板 | **T5-E1（SPARKLEIOT T5AI DEV）**：ST7789 240×320 触控彩屏 + CST816X 触控 + GC2145 DVP 摄像头 + 内置音频 codec/功放 + microSD | 门外交互：待机提醒、放入/取出选择、结果显示 |
| 内模组 | **Seeed XIAO ESP32S3 Sense**（8MB PSRAM，OV3660 摄像头 + PDM 麦克风 + microSD 槽） | 门内感知：扫码触发、条码解码、视觉兜底、语音播报、事件检测 |
| 音频（内模组） | MAX98357A（I2S）+ 3W 喇叭 | “叮 + 名称”播报 |
| 外设（内模组） | 光敏（门开检测）、KY-009 补光、轻触按键 | 事件触发与扫码触发 |

> T5-E1 板载摄像头已确认可用（GC2145 DVP），**外挂 XIAO Sense 不再用于平板侧**；XIAO Sense 仅作内模组。

## 3. 固件功能需求

1. **待机态**：从云端 / 本地拉取库存，屏幕常显临期 / 过期置顶列表；
2. **触摸选择**：点击屏幕弹出【放入】【取出】——动作由**外置平板触屏**选择，经云端下发内模组（见 §5.2）；
3. **扫描引导**：提示“请把食品放到镜头前”，内模组按键触发扫码（或经过事件自动触发）；
4. **板载拍照**：GC2145（平板）/ OV3660（内模组）抓帧 → 组装 multipart 上传云端；
5. **结果展示**：收到识别 JSON 后屏幕显示品名、日期时间、保质期 / 到期日、建议容器；
6. **库存变更**：用户确认 → 云端库存 +1（放入）/ -1（取出）；
7. **声音反馈**：扫描“咔嚓 / 叮”，过期警示音；取出模式提示音区分；
8. **断网降级**：显示本地最近库存 + “网络不好，先不扫描”；内模组离线队列补传。

## 4. 交互流程（放入 / 取出）

### 4.1 待机页

- 屏幕显示两个大按钮：**【放入】** 与 **【取出】**（可叠加临期 / 过期提醒）。

### 4.2 放入 / 取出流程

1. 外置平板点【放入】/【取出】→ 云端下发动作 → 内模组进入扫码模式；
2. 拍照预览（实时画面作背景）→ **3 秒倒计时**（半透明大数字 3→2→1，占屏约一半）→ 归零自动拍照 + “咔嚓”；
3. 照片实时上传云端（15s 超时）→ “正在识别…”；
4. 收到结果 → 屏幕显示品名、当天日期时间、保质期 / 到期日、建议容器；
5. 用户确认 → 库存 +1 / -1 → 回待机页。

### 4.3 失败与兜底

- 上传失败 / 超时：“网络不好，请重试”，不丢本次动作，可重拍；
- 低置信：“没看清，请重新对准再拍”，不写入库存；
- 断网：显示本地最近一次库存与提醒 + “网络不好，先不扫描”；内模组断网入队、恢复重传。

## 5. 云端 API 契约

### 5.1 扫描

`POST https://shike.live/api/scan`（multipart/form-data）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `image` | JPEG | 640×480，质量 ~50–70 |
| `deviceId` | string | 内模组 `shike-xiao-001`；平板 `xzd-t5e1-001` |
| `action` | string | `in`（放入）/ `out`（取出） |
| `container` | string | 冰箱 \| 零食柜 \| 药盒 \| 调料柜 \| 主食柜 |
| `timestamp` | string | `YYYY-MM-DD HH:mm:ss`（NTP 校时，北京时间） |
| `requestId` | string | 幂等键（可选，重试不重复入库） |

响应：`{"code":0,"name":"...","scannedAt":"...","expiryDate":"...","daysLeft":2,"suggestedContainer":"冰箱","confidence":0.92,"keepDays":3,"stockTotal":12}`；`code!=0` 或 HTTP 非 200 按失败处理。

### 5.2 设备指令下发（平板 → 内模组 · 后端新增中）

- `POST /api/device/task`：平板选择动作后调用 `{deviceId, action}`，云端保存“当前动作”；
- `GET /api/device/task?deviceId=...`：内模组扫码前取动作，`action=null` 时默认 `in`；
- 详细契约见 `docs/03-软件/后端对接说明.md` §9。

## 6. 构建与烧录 SOP

### 6.1 外置平板（T5-E1 · TuyaOpen）

```bash
cd /Users/lwl/TuyaOpenIDE/TuyaOpenSDK && . ./export.sh
"$OPEN_SDK_ROOT/tools/tyutool/tyutool_cli" --plain list-ports --json   # 先识别端口
"$OPEN_SDK_ROOT/tools/tyutool/tyutool_cli" --plain write -d t5 \
  -f <工程>/source/embedded/dist/<工程>_QIO_<版本>.bin \
  -p <list-ports 输出端口> -b 460800
```

- 产物：`QIO`（全量，烧录主用）/ `UA`（升级包）/ `UG`（备用），**三者不混用**；
- **端口每次插拔会变**，先 `list-ports` 再烧；T5 双串口，失败换另一个口。

### 6.2 内模组（XIAO · Arduino IDE）

1. 安装 esp32 包 ≥2.0.8，板卡选 `Seeed XIAO ESP32S3`；
2. 打开 `firmware/inner-module/` 下示例，先改各文件夹内 `config.h`（WiFi / 设备号 / 容器）；
3. 选择 USB 端口上传；**端口丢失 / 上传失败 → 按住 BOOT 再插 USB** 进 BootLoader 重传。

## 7. 引脚表

### 7.1 外置平板（T5-E1 板载）

| 外设 | 连接 |
|---|---|
| 显示 ST7789 240×320（SPI0） | SCK=44、MOSI=46、CS=45、DC=47、RST=6、BL=9 |
| 触控 CST816X（I2C1） | SCL=20、SDA=21、RST=23 |
| 摄像头 GC2145（DVP） | 控制 I2C0：SCL=0、SDA=1；24MHz MCLK；DVP 数据总线平台固定 |
| 音频 | 内置 codec + 功放，spk_en=GPIO7（高有效） |
| 按键 | GPIO8（低有效，下降沿中断） |
| microSD（SDIO MODE1） | CLK=14、CMD=15、D0–D3=16~19 |
| UART0 | TX=11、RX=10（115200） |

### 7.2 内模组（XIAO ESP32S3 Sense 官方引脚）

| 外设 | 连接 |
|---|---|
| 摄像头 | XCLK=10、PCLK=13、VSYNC=38、HREF=47、SIOD=40、SIOC=39、D0–D7=15/17/18/16/14/12/11/48 |
| PDM 麦克风（板载） | DATA=41、CLK=42（勿占用） |
| 用户灯（板载） | GPIO21 |
| SD 卡（板载，冲刺期不用） | CS=3、SCK=7、MISO=8、MOSI=9 |
| I2S 功放 MAX98357A | BCLK=5、LRC=6、DIN=7 |
| 按键 / 光敏 / 补光 | GPIO2 / GPIO1 / GPIO3 |

> ⚠️ GPIO3/7/8/9 为 SD 卡引脚；**冲刺期不使用 SD 卡**才可复用作 LED/音频，启用 SD 前需调整引脚方案。完整配置见 `firmware/inner-module/内模组-00-共享配置/config.h`。

## 8. 字体与字符集（屏显约束，必读）

> 屏幕是 240×320 低分辨率小屏，中文显示**必须用点阵字库，禁止矢量 TTF**。

| 用途 | 点阵规格 |
|---|---|
| 中文正文 / 按钮 / 结果页 | **16×16 GB2312 点阵字库（HZK16）**，原样点对点输出，不缩放 |
| 数字 / 字母 / 符号 | 8×16 或 16×16 ASCII 点阵 |
| 倒计时大数字 3→2→1 | 16×16 或 24×24 点阵，**整数倍（×2 / ×3）最近邻放大** |

硬性约束：

1. **禁止 TrueType(.ttf) 等矢量字体**与实时缩放渲染；
2. **禁止抗锯齿、灰度、亚像素渲染**：纯 1-bit 二值点阵，字符像素严格对齐网格；
3. **字符集限定 GB2312 简体中文 + ASCII**，固件所有界面文案必须在字库字符集内，避免缺字乱码；
4. 倒计时“半透明”仅指位图字形 + 整数 alpha 混合，字形本身仍为点阵。

## 10. 注意事项

- 平板端口每次插拔会变：先 `list-ports` 再烧，不要写死端口；
- T5 是双串口设备：烧录用主口，失败换另一个口重试；
- QIO 为全量镜像，UG / UA 不混用；后续升级用 UA；
- 内模组四份示例（02/03/04/05/D2）的帧管线规则见 `firmware/README.md`；
- 产品名：**食刻**（食刻在场，不浪费每一份食材），固件屏显文字同步。
