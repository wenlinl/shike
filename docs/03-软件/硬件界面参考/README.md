# 食刻 · 硬件界面参考（给烧录 AI）· v1

> 目标板：T5-E1（SPARKLEIOT T5AI DEV）｜屏幕：ST7789 **240×320** 触控彩屏（SPI0）｜摄像头：板载 GC2145 DVP 仅作安装自检，不参与日常扫码
> 用途：作为「食刻」外置平板 v1 固件 UI 的实现参考。每个界面一个独立 HTML 文件，**页面本体即为 240×320（与硬件屏幕等大，无外围页面）**；右上角 **i** 角标可切换查看实现说明浮层（状态、尺寸、色值、API 对应）。
> 口径：**HW-v1 门外交互屏**——扫码识别由内模组完成（条码优先 + 语音），平板只做动作下发、结果展示、库存与汇总确认；改造方案见 [外置平板-v1-界面与固件改造方案](../外置平板-v1-界面与固件改造方案.md)。

## 界面清单与固件状态映射

| 文件 | 固件状态 | 触发条件 | 核心动作 |
|---|---|---|---|
| `01-待机页.html` | STANDBY | 开机/任意流程结束 | 临期提醒 + 底部三列统计；点【放入/取出】→ POST /api/device/task |
| `02-等待扫码.html` | WAIT_SCAN | 动作下发成功 | 提示对准内模组镜头；轮询 GET /api/scan/latest（2–3s） |
| `03-识别结果-放入.html` | RESULT(in) | 轮询到放入事件 | 展示品名/时间/保质期/建议容器（云端建议，chips 只展示）；完成回待机 |
| `04-识别结果-取出.html` | RESULT(out) | 轮询到取出事件 | 同上；库存 −1 已由内模组扫码完成 |
| `05-库存页.html` | STOCK | 点待机页提醒/入口 | 按容器列表，临期/过期置顶，可滚动 |
| `06-汇总待确认.html` | SUMMARY | 关门结算有可疑项 | 放入/取出/中途取出/未识别统计 + 一键确认/逐条修正 |
| `07-断网离线.html` | OFFLINE | 断网 | 本地最近库存 + "先不扫描"；恢复回 STANDBY |
| `08-启动页.html` | BOOT | 上电 | 品牌 + 连接云端，成功 STANDBY / 失败 OFFLINE |

## 交互与验收对照（固件需求 §5）

- 待机页两个大按钮：**放入**（红实心）、**取出**（白底红描边），触控目标 ≥ 80px 高；点击后 `POST /api/device/task`（带 `X-Device-Token`）→ WAIT_SCAN；
- WAIT_SCAN 每 2–3s 轮询 `GET /api/scan/latest?deviceId=xzd-t5e1-001`，有结果进 RESULT；15s 无结果提示后回 STANDBY；
- 结果页数据全部来自云端（内模组 POST /api/scan 后落库），平板**不再拍照上传**；建议容器 chips 只展示不切换；
- 库存页 `GET /api/items?container=…`，按剩余天数升序，expired/soon 置顶标色；
- 汇总页 `GET /api/summary/pending` + `POST /api/summary/confirm`（后端契约待补）；
- 断网显示本地缓存并禁用扫描；设备端不持有任何 API Key，只持 `X-Device-Token`。
- 设备端不持有任何 API Key。

## 使用方式

直接把这整个文件夹（或单个界面 HTML）交给硬件烧录 AI；每个文件的 `.screen` 区即 240×320 的 UI，文件下方「实现说明」区是给固件的结构化提示。`index-总览.html` 一览页；PNG 预览图存放于 `media/软件示意图/硬件设备界面/`（v1 页面截图待更新）。
