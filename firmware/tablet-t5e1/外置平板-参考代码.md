## 1. v1 已实施内容

```text
BOOT → STANDBY（放入/取出 + 临期提醒）
   → 点【放入/取出】→ POST /api/device/task → WAIT_SCAN
   → 每 3s 轮询 GET /api/scan/latest（内模组扫码事件）→ RESULT in/out → 回 STANDBY
   → 15s 无结果 → 提示重试
辅助：STOCK（库存页，device/state 摘要 + 关门结算入口）
     SUMMARY（汇总待确认，演示数据 + 全部确认）
     OFFLINE（断网本地模式）
```

- 平板**不再拍照上传**：摄像头 GC2145 仅保留安装自检，帧回调直接忽略；
- 待机页按钮动作 = 云端下发（`XZD_DEVICE_TOKEN` 鉴权），扫码/识别/入账全部由内模组完成；
- 库存页数据源 `GET /api/device/state`（约 1KB，避开 `/api/items` 13KB 大响应导致的 TLS 堆崩溃问题）；
- 汇总页：后端 `/api/summary/pending` + `/api/summary/confirm` 就绪前为演示数据，确认按钮本地清零回待机。
